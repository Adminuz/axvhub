/* Figma Dev Mode bergan (taxminan) */
.karta { width: 280px; padding: 16px; border-radius: 12px; }

/* Loyihamizga moslangan */
.karta { max-width: 17.5rem; padding: 1rem; border-radius: 0.75rem; }
Qotirilgan width: 280px ni to'g'ridan-to'g'ri ko'chirmang: responsiv maket uchun max-width va rem ishlating (8-sinf, 15–16-darslar).

Dizaynni topshirish

  1. Faylni sinfdoshingizga Can view ruxsati bilan ulashing va havolani tekshiring.
  2. Sinfdoshingiz dizaynida kamida 2 ta sharh qoldiring (1 ta taklif bilan).
