Tugma holatlari CSS da


.tugma { background: #17e; color: #fff; padding: 12px 24px; border-radius: 8px; }
.tugma:hover { background: #15b; }

.tugma:disabled { background: #ccc; color: #666; }

Auto layout → CSS

Pastga bosing: holatlar

Kitob kartasi

  1. Karta uchun frame chizing: rasm, nom, muallif va «O'qish» tugmasi.
  2. Auto layout (vertikal, gap 12, padding 16) bering va tugmani komponentga aylantiring.
  3. Kartani komponentga aylantirib, variant Holat = oddiy / tanlangan qo'shing va 3 nusxa joylashtiring.
