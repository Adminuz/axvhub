9-sinfBusiness Intelligence4-hafta

Savol 1/20

Redundansiya nima?

Masalan, mijoz telefoni har bir buyurtma qatorida takrorlanadi.

Savol 2/20

Mijoz telefoni faqat bitta qatorda yangilanib, boshqalarida eskisi qoldi. Bu qanday anomaliya?

Takrorlangan ma'lumot qisman yangilanganda ziddiyat paydo bo'ladi.

Savol 3/20

1NF ning asosiy talabi qaysi?

«Sichqoncha, Klaviatura» kabi bir katakdagi ro'yxat 1NF ni buzadi.

Savol 4/20

2NF qanday bog'liqlikni yo'qotadi?

2NF — butun kalitga bog'liqlik; tranzitiv bog'liqlik 3NF da yo'qotiladi.

Savol 5/20

Xodimlar(XodimID, Ism, BolimID, BolimNomi) — BolimNomi BolimID ga bog'liq. Qaysi shakl buzilgan?

Kalit bo'lmagan ustun boshqa kalit bo'lmagan ustunga bog'liq — tranzitiv bog'liqlik.

Savol 6/20

Star schema markazidagi jadval qanday ataladi?

Fact jadvalda raqamlar (Soni, Summa) va Dimension'larga FK lar turadi.

Savol 7/20

Nega BI hisobotlari uchun ba'zan denormalizatsiya qilinadi?

Tahlilda ko'p o'qiladi; kamroq bog'lash bilan tezroq natija olinadi.

Savol 8/20

Server talab qilmaydigan, bitta faylda ishlaydigan va telefon ilovalarida ko'p ishlatiladigan RDBMS qaysi?

SQLite — ichki (embedded) baza, smartfon va brauzerlarda bor.

Savol 9/20

Ikki o'quvchiga bir xil ID berildi. Qaysi yaxlitlik turi buzildi?

PRIMARY KEY takrorlanmasligi — entity integrity.

Savol 10/20

Buyurtmada mavjud bo'lmagan MijozID = 99 ko'rsatildi. Qaysi cheklov buni to'xtatadi?

FK faqat mavjud PK qiymatiga ishora qilishiga ruxsat beradi — referential integrity.

Savol 11/20

Narx faqat musbat bo'lishi uchun qaysi cheklov yoziladi?

CHECK shartga mos bo'lmagan qiymatni rad etadi (domain integrity).

Savol 12/20

SQL Server da o'zbekcha O'g'iloy ismini qanday yozish to'g'ri?

Matn ichidagi apostrof ikkilantiriladi; N — Unicode matn.

Savol 13/20

ACID dagi «A» (Atomicity) nimani bildiradi?

Masalan, pul yechildi-yu qo'shilmasa — hammasi bekor qilinadi (ROLLBACK).

Savol 14/20

SQL nega deklarativ til deyiladi?

«Qanday» emas, «nima» — deklarativ yondashuv.

Savol 15/20

SELECT qaysi toifaga kiradi?

DQL — Data Query Language; SELECT ma'lumotni faqat o'qiydi.

Savol 16/20

SELECT Narx, Nomi FROM Mahsulotlar; natijasida birinchi ustun qaysi?

Ustunlar SELECT da yozilgan tartibda chiqadi.

Savol 17/20

AS nima qiladi?

Jadvaldagi asl nom o'zgarmaydi.

Savol 18/20

Narx = 80000, Soni = 25. Narx * Soni AS OmborQiymati nimaga teng?

80000 × 25 = 2 000 000.

Savol 19/20

SQL Server da SELECT 7 / 2; natijasi qanday?

Ikki butun son bo'linganda butun natija; 3.5 uchun 7 / 2.0 yozing.

Savol 20/20

6 ta mahsulot 3 xil kategoriyada. SELECT DISTINCT Kategoriya FROM Mahsulotlar; nechta qator qaytaradi?

DISTINCT takrorlanuvchi qiymatlarni olib tashlaydi.

Natijangiz
