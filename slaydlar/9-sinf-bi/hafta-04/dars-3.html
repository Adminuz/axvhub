02

SELECT va FROM

Nimani va qayerdan

SELECT * - barcha ustunlar


SELECT *
FROM Mahsulotlar;

SELECT

Nimani olamiz. * - hamma ustun.

FROM

Qaysi jadvaldan.

Kerakli ustunlar


SELECT Nomi, Narx
FROM Mahsulotlar;
Ustunlar siz yozgan tartibda chiqadi. Hisobotlarda SELECT * o'rniga faqat kerakli ustunlar.

AS - taxallus


SELECT Nomi AS Mahsulot,
       Narx AS [Narx (so'm)]
FROM Mahsulotlar;

Jadvaldagi asl nom o'zgarmaydi. Bo'sh joyli nom SQL Server da [...] ichida.

Mini-test

SELECT Narx, Nomi FROM Mahsulotlar; natijasida birinchi ustun qaysi?

03

Sodda ifodalar

Hisoblangan ustunlar, DISTINCT, TOP

Hisoblangan ustunlar


SELECT Nomi,
       Narx * Soni        AS OmborQiymati,
       Narx * 1.12        AS QQS_bilan,
       Narx - Narx * 0.10 AS Chegirma10
FROM Mahsulotlar;

Sichqoncha: 2000000, 89600, 72000. QQS - 12%.

Bo'lish tuzog'i

Butun sonlar

SELECT 7 / 2; → 3
VS

Kasr bilan

SELECT 7 / 2.0; → 3.5

SQL Server da ikki butun sonni bo'lish butun natija beradi.

Matnni birlashtirish


SELECT Nomi + N' (' + Kategoriya + N')' AS ToliqNom
FROM Mahsulotlar;
-- Sichqoncha (Aksessuar)

SELECT CONCAT(Nomi, N' (', Kategoriya, N')') AS ToliqNom
FROM Mahsulotlar;

FROM Mahsulotlar;

Tartibsiz TOP qaysi 3 qatorni berishi kafolatlanmaydi. «Eng qimmat 3 ta» uchun keyin ORDER BY o'rganamiz.
