Savol 1/10

SQL nega deklarativ til deyiladi?

«Qanday» emas, «nima» — deklarativ yondashuv.

Savol 2/10

SELECT qaysi toifaga kiradi?

DQL — Data Query Language; SELECT ma'lumotni faqat o'qiydi.

Savol 3/10

CREATE TABLE qaysi toifaga kiradi?

DDL tuzilmani yaratadi va o'zgartiradi.

Savol 4/10

SELECT * FROM Mahsulotlar; nima qaytaradi?

* — barcha ustunlar; filtr bo'lmagani uchun barcha qatorlar.

Savol 5/10

SELECT Narx, Nomi FROM Mahsulotlar; natijasida birinchi ustun qaysi?

Ustunlar SELECT da yozilgan tartibda chiqadi.

Savol 6/10

AS nima qiladi?

Jadvaldagi asl nom o'zgarmaydi.

Savol 7/10

Narx = 80000, Soni = 25. Narx * Soni AS OmborQiymati nimaga teng?

80000 × 25 = 2 000 000.

Savol 8/10

SQL Server da SELECT 7 / 2; natijasi qanday?

Ikki butun son bo'linganda butun natija; 3.5 uchun 7 / 2.0 yozing.

Savol 9/10

6 ta mahsulot 3 xil kategoriyada. SELECT DISTINCT Kategoriya FROM Mahsulotlar; nechta qator qaytaradi?

DISTINCT takrorlanuvchi qiymatlarni olib tashlaydi.

Savol 10/10

SQL Server dagi SELECT TOP 3 ... ning PostgreSQL/MySQL dagi muqobili qaysi?

PostgreSQL, MySQL va SQLite da LIMIT ishlatiladi.

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.
