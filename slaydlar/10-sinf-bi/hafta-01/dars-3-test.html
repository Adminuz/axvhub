Savol 1/10

CSV formati qanday ma'lumot saqlaydi?

CSV - satrlarga bo'lingan, ajratgich bilan ustunlarga ajratilgan plain text.

Savol 2/10

CSV da ma'lumot turlari (integer, date) nega saqlanmaydi?

Faylda faqat belgilar bor, qaysi ustun qanday turda ekanini bildiruvchi schema yo'q.

Savol 3/10

JSON ning CSV dan asosiy afzalligi nima?

JSON obyekt ichida obyekt va massivlarni erkin saqlaydi.

Savol 4/10

Qaysi papkada tozalangan, standartlashtirilgan (Parquet/CSV) fayllar turadi?

Silver - tozalangan va normalizatsiya qilingan zona.

Savol 5/10

pd.json_normalize() ning vazifasi nima?

Daraxtsimon JSON obyektlari satr va ustunli jadval shakliga keltiriladi (flattening).

Savol 6/10

101;"1-maktab, Toshkent";1250;2024 satri to'g'ri o'qilishi uchun nima yoziladi?

Ajratgich nuqta-vergul; standart read_csv esa vergul qidiradi, shuning uchun sep=';' ko'rsatiladi.

Savol 7/10

pd.read_csv(..., encoding="utf-8") UnicodeDecodeError berdi. Qanday chora ko'riladi?

Eski yoki Excel fayllar ko'pincha cp1251 da bo'ladi; except UnicodeDecodeError da shu kodlash sinaladi.

Savol 8/10

Bosh direktor uchun tayyor monthly_revenue_kpi.csv qaysi papkaga tegishli?

Gold - yakuniy hisoblangan tahliliy jadvallar va KPI zonasi.

Savol 9/10

{"ism": "Jasur", "kontakt": {"shahar": "Buxoro"}} json_normalize dan keyin qanday ustun nomi chiqadi?

Ichki kalitlar nuqta bilan birlashtiriladi: kontakt.shahar.

Savol 10/10

API loglarini saqlashda nega ko'pincha JSON tanlanadi, BI uchun esa qanday muammo bor?

JSON web va API standarti, ammo Power BI va SQL tekis jadvalni yoqtiradi; kalit nomlari takror yozilib hajm ham oshadi.
