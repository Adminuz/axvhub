VS

Virtual muhit (venv)

Har loyihaga alohida izolyatsiyalangan papka.

Loyiha uchun kerakli kutubxonalargina.

A loyihaga Django 3.0, B loyihaga Django 4.0 kerak bo'lishi mumkin: venv bu muammoni hal qiladi.

Muhitni tayyorlash

$ mkdir e_library && cd e_library
$ python -m venv .venv
$ source .venv/bin/activate
$ pip install fastapi "uvicorn[standard]" sqlalchemy asyncpg alembic pydantic-settings
$ pip install "python-jose[cryptography]" "passlib[bcrypt]" python-multipart

Windows da faollashtirish: .venv\Scripts\activate

03

MB dizayni

Kodgacha qog'ozda chizamiz

Bog'lanish turlari

One-to-One (1:1)

Foydalanuvchi va pasport ma'lumoti.

One-to-Many (1:N)

Bitta user ko'p post yozadi. Eng ko'p ishlatiladi.

Many-to-Many (M:N)

Talabalar va fanlar. Bog'lovchi jadval orqali.

PK qatorni aniqlaydi, FK boshqa jadvalga ishora qiladi.

E-Library ER diagrammasi

Ikkita 1:N bog'lanish

users (1) - (N) books, categories (1) - (N) books. Bloklarga bosing.

books jadvali: asosiy maydonlar

MaydonTuriIzoh
titlevarchar(200)NOT NULL
file_pathtextyuklangach to'ladi
is_publishedbooldefault false
owner_idUUID FKusers.id (CASCADE)
category_idUUID FKcategories.id (RESTRICT)

Indekslar keyinroq: books(title), books(owner_id), books(category_id).

04

Dastlabki sozlamalar

Config, baza va ishga tushirish

.env va config.py

# .env:  DB_HOST=localhost  DB_NAME=e_library ...
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    app_name: str = "E-Library API"
    db_host: str
    db_name: str
    db_user: str
    db_password: str
    model_config = SettingsConfigDict(env_file=".env")

settings = Settings()

Pastga bosing: nega .env?

Nega .env?

Maxfiy ma'lumot (MB paroli, API kalit) hech qachon kod ichida ochiq yozilmaydi.
BaseSettings qiymatni Python obyektiga o'giradi va tekshiradi. Unutilgan o'zgaruvchi bo'lsa xato beradi.
.env ni GitHub ga yuklamang; .env.example dan nusxa oling.

Engine va session

Asinxron ulanish

Engine = yo'l, session = yo'ldagi mashina. Bloklarga bosing.

main.py: boshlanishi

from fastapi import FastAPI
from app.core.config import settings

def create_app() -> FastAPI:
    app = FastAPI(title=settings.app_name)
    return app

app = create_app()

main.py: /health qo'shildi

from fastapi import FastAPI
from app.core.config import settings

def create_app() -> FastAPI:
    app = FastAPI(title=settings.app_name)

    @app.get("/health", tags=["system"])
    async def healthcheck() -> dict:
        return {"status": "ok"}

    return app

app = create_app()
