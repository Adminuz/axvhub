Access va Refresh tokenlar juftligi

Access Token (Qisqa muddat)

15-60 daqiqa yashaydi. Har bir API so'rovida yuboriladi: Authorization: Bearer <token>.

O'g'irlangan taqdirda ham muddati tezda tugaydi.

Refresh Token (Uzoq muddat)

7-30 kun yashaydi. Faqat yangi access token olish uchun ishlatiladi.

Foydalanuvchini har 15 daqiqada qayta login qilishdan qutqaradi.

Email orqali identifikatsiya va kengaytirilgan profil

src/apps/accounts/models.py

class User(TimeStampedModel, AbstractBaseUser, PermissionsMixin):
    email = models.EmailField(unique=True)
    full_name = models.CharField(max_length=160, blank=True)
    avatar = models.ImageField(upload_to="avatars/", blank=True, null=True)

    is_active = models.BooleanField(default=True)
    is_staff = models.BooleanField(default=False)

    objects = UserManager()

    USERNAME_FIELD = "email"
    REQUIRED_FIELDS: list[str] = []

    def __str__(self) -> str:
        return self.email

Nima sababdan JWT tokenda Signature (raqamli imzo) kerak?

To'g'ri! Signature tokenning daxlsizligini ta'minlaydi: u serverning maxfiy SECRET_KEY kaliti bilan imzolanadi va soxtalashtirishdan himoya qiladi.

Dasturchilar ko'p yo'l qo'yadigan xatolar

Xato: JWT Payload ichida maxfiy parollar yoki bank kartasi ma'lumotlarini saqlash (JWT ochiq o'qiladi!).
To'g'ri: Payload ichida faqat ommaviy ma'lumotlar saqlansin: user_id, email, roles.
