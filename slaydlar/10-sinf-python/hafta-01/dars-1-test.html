Savol 3/10

SPA (Single Page Application) qaysi rendering usuliga xos?

SPA da sahifa qayta yuklanmaydi, interfeys brauzerda JavaScript orqali yangilanadi (CSR/USR).

Savol 4/10

REST da «Stateless» tamoyili nimani bildiradi?

Kerakli barcha ma'lumot (token, parametrlar) so'rovning o'zida bo'lishi kerak.

Savol 5/10

Savol 6/10

5-raqamli maqola sarlavhasini faqat qisman o'zgartirish uchun qaysi metod mos?

PATCH qisman yangilaydi, PUT esa resursni to'liq almashtiradi.

Savol 7/10

DRF dagi Serializer qanday vazifani bajaradi?

Serializer — modellar va JSON o'rtasidagi tarjimon hamda validatsiya vositasi.

CSR sahifasi ochilganda server avval nima yuboradi, so'ng brauzer nima qiladi?
