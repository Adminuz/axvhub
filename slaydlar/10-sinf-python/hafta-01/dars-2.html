Jadvallar va ularning relyatsion bog'lanishlari

Relyatsion xavfsizlik: PROTECT vs CASCADE

models.PROTECT

Kategoriya o'chirilganda postlar o'chib ketmasligi uchun o'chirishni taqiqlaydi.

Maqolalar ota kategoriyasiz qolib ketmaydi.

VS

models.CASCADE

Post o'chirilganda, unga tegishli barcha izohlar ham birga avtomatik o'chiriladi.

Baza keraksiz qoldiq ma'lumotlardan tozalanadi.

02

Virtual muhit va o'rnatish

Loyiha izolyatsiyasi va talab qilinadigan kutubxonalar

Nega virtual muhit (venv) shart?

Har bir loyihaning kutubxona va versiyalar to'qnashuvini oldini oladi

Virtual muhitni ishga tushirish

Terminalda ketma-ket bajariladigan buyruqlar

Terminal / Bash 
# 1. Virtual muhit yaratish
python3 -m venv venv

# 2. Faollashtirish (macOS / Linux)
source venv/bin/activate
# Windows uchun: venv\Scripts\activate

# 3. Asosiy paketlarni o'rnatish
pip install django djangorestframework python-dotenv psycopg2-binary

# 4. requirements.txt hosil qilish
pip freeze > requirements.txt
03

Clean Architecture

Yirik kompaniyalar andozasidagi modulli loyiha strukturasi

NewsPortal papkalar strukturasi

src/config/

Loyiha sozlamalari, URL marshrutlar va WSGI/ASGI fayllari jamlangan boshqaruv markazi.

src/apps/

Domenlar bo'yicha ajratilgan mustaqil ilovalar: news, comments, accounts, common.

.env & configs

Maxfiy kalitlar, baza parollari va muhit o'zgaruvchilari uchun maxsus qatlam.

Xavfsizlik: .env fayli qanday ishlaydi?

Maxfiy kalitlar koddan ajratiladi va Git-ga yuklanmaydi

settings/base.py sozlamasi

# src/config/settings/base.py
from pathlib import Path
import os
from dotenv import load_dotenv

BASE_DIR = Path(__file__).resolve().parent.parent.parent
load_dotenv(BASE_DIR.parent / ".env")

INSTALLED_APPS = [
    # Django standart ilovalari...
    "rest_framework",  # DRF kutubxonasi
    "apps.common",
    "apps.news",
    "apps.comments",
]

Django ORM va Migratsiyalar

  1. Model yaratiladi: Python klassi sifatida jadval maydonlari yoziladi (models.Model).
  2. makemigrations: Django modellardagi o'zgarishlarni tahlil qilib, migratsiya rejasini tuzadi.
  3. migrate: Ushbu reja asosida ma'lumotlar bazasida (SQLite / PostgreSQL) haqiqiy jadvallar ochiladi.

Loyihani ishga tushirish bosqichlari

1-qadam: Muhitni tayyorlash

Terminalda python3 -m venv venv va source venv/bin/activate orqali toza muhit ochiladi.

2-qadam: Paketlarni o'rnatish

pip install django djangorestframework python-dotenv buyruqlari bilan backend vositalari yuklanadi.

3-qadam: Loyiha va sozlamalar

django-admin startproject config src/ qilinib, settings/base.py ga DRF ulanadi.

Tezkor bilim tekshiruvi

Nima uchun Category va Post o'rtasida models.PROTECT qo'yish to'g'ri yondashuv hisoblanadi?

To'g'ri! models.PROTECT ma'lumotlar butunligini saqlaydi: ichida maqolalar bor kategoriyani tasodifan o'chirib yuborishning oldini oladi.

Dasturchilar ko'p yo'l qo'yadigan xatolar

To'g'ri: .env faylidan foydalaning va .gitignore fayliga .env ni yozib qo'ying.
