02

Fayl yuklash (Upload)

Multipart/form-data va Pillow tekshiruvi

Fayl yuklash oqimi

Mijozdan to server diskigacha bo'lgan yo'l

PostViewSet da upload_cover actioni

@action(
    methods=["post"],
    detail=True,
    url_path="upload-cover",
    parser_classes=[MultiPartParser, FormParser],
)
def upload_cover(self, request, slug=None):
    post = self.get_object()
    serializer = PostCoverUploadSerializer(post, data=request.data, partial=True)
    serializer.is_valid(raise_exception=True)
    serializer.save()
    return Response(serializer.data, status=status.HTTP_200_OK)
03

Faylni yuklab olish (Download)

FileResponse va oqimli uzatish

download_cover actioni

@action(methods=["get"], detail=True, url_path="download-cover")
def download_cover(self, request, slug=None):
    post = self.get_object()
    if not post.cover_image:
        raise Http404("Muqova rasmi topilmadi")

    return FileResponse(
        post.cover_image.open("rb"),
        as_attachment=True,
        filename=post.cover_image.name.split("/")[-1]
    )
as_attachment=True parametri brauzerda rasmni shunchaki ko'rsatmasdan, kompyuterga yuklab olishni boshlaydi.

Tezkor bilim tekshiruvi

Nima uchun rasmlarning o'zi ma'lumotlar bazasida emas, server diskida saqlanadi?

To'g'ri! Katta hajmdagi fayllarni diskda yoki bulutli xotirada saqlash va bazada faqat uning yo'lini (path) yozib qo'yish jahon standartidir.

Dasturchilar ko'p yo'l qo'yadigan xatolar

Xato: Fayl yuklashda uning hajmi va formatini tekshirmaslik (foydalanuvchi virusli yoki 500 MB li fayl yuklashi mumkin).
To'g'ri: Har doim serializerda validate_cover_image orqali MIME turi va maksimal hajmni qat'iy tekshiring.
