src/apps/common/pagination.py

from rest_framework.pagination import PageNumberPagination

class DefaultPageNumberPagination(PageNumberPagination):
    page_size = 10
    page_size_query_param = "page_size"
    max_page_size = 100
max_page_size = 100 parametri xaker ataylab ?page_size=1000000 deb serverni qotirib qo'yishining oldini oladi.
02

Throttling (Rate Limiting)

So'rovlar oqimini cheklash va serverni himoya qilish

Throttling qanday ishlaydi?

Ortiqcha so'rovlar darhol 429 Too Many Requests bilan to'xtatiladi

DRF dagi asosiy Throttle klasslari

AnonRateThrottle

Tizimga kirmagan mehmonlar uchun (IP bo'yicha hisoblaydi, masalan: 60/min).

UserRateThrottle

Ro'yxatdan o'tgan foydalanuvchilar uchun (User ID bo'yicha, masalan: 300/min).

ScopedRateThrottle

Alohida nozik endpointlar uchun (masalan, login uchun qat'iy: 10/min).

settings/base.py sozlamalari

REST_FRAMEWORK = {
    # Global Pagination
    "DEFAULT_PAGINATION_CLASS": 
        "apps.common.pagination.DefaultPageNumberPagination",
    "PAGE_SIZE": 10,

    # Global Throttling
    "DEFAULT_THROTTLE_CLASSES": (
        "rest_framework.throttling.AnonRateThrottle",
        "rest_framework.throttling.UserRateThrottle",
    ),
    "DEFAULT_THROTTLE_RATES": {
        "anon": "60/min",
        "user": "300/min",
        "login_anon": "10/min",
    },
}

Throttling qanday tekshiriladi?

1-qadam: Oddiy so'rovlar

Brauzerda GET /api/v1/posts/ chaqiriladi — server xotirasida soniya hisoblagich boshlanadi.

2-qadam: Limitga yetish

1 daqiqa ichida so'rovlar soni 60 taga yetganda, kesh chegarasi to'ladi.

3-qadam: 429 Blokirovkasi

61-so'rovdan boshlab {"detail": "Request was throttled. Expected available in 55 seconds."} qaytadi.

Nima uchun pagination sozlamasida max_page_size berilishi shart?

To'g'ri! Agar maksimal hajm cheklanmasa, foydalanuvchi ulkan son kiritib yana xuddi paginatsiyasiz kabi server xotirasini to'ldirib qo'yishi mumkin.

Dasturchilar ko'p yo'l qo'yadigan xatolar

Xato: Login sahifasiga umumiy rate limit qo'yish (xakerlar soniyasiga o'nlab parollarni sinab ko'rishi mumkin).
To'g'ri: Login endpointiga LoginAnonThrottle (10/min) kabi qat'iy cheklov o'rnating.
