Takrorlash

val ball = 75. when (ball) { in 70..89 -> "Yaxshi"; else -> "Boshqa" } nima qaytaradi?

75 70..89 oralig'iga kiradi, shuning uchun birinchi shart bajariladi.
01

for sikli

Oraliq bo'yicha takrorlash

for sikli qanday ishlaydi

for: kvadratlar jadvali


for (n in 1..9) {
    println("$n * $n = ${n * n}")
}
1..9 ikkala chegarani ham o'z ichiga oladi; 1 until 9 esa 9 ni kiritmaydi (1..8).

Mini-test

for (i in 1 until 5) println(i) qaysi sonlarni chiqaradi?

until oxirgi chegarani kiritmaydi.
02

downTo, step, while

Teskari sanash, qadam va shartli sikllar

while va do-while farqi

while va do-while


var i = 10
while (i > 7) {
    println(i)
    i--
}
var j = -1
do {
    println("j = $j")
    j--
} while (j > 0)
do-while da shart noto'g'ri bo'lsa ham tana bir marta bajariladi: j = -1 chop etiladi.

Mini-test

var i = 5; while (i < 3) { println(i) } nechta marta chop etadi?

Shart boshidan noto'g'ri, while tanasi ishlamaydi.
03

break va continue

Siklni boshqarish va ichma-ich sikllar

break va continue yo'li

continue va ichma-ich sikl


for (n in 1..7) {
    if (n == 5) continue
    print("$n ")
}
println()
for (a in 1..3) {
    for (b in 1..3) print("${a * b}\t")
    println()
}
continue da 5 tashlab o'tiladi: natija 1 2 3 4 6 7. Ichki sikl har bir a uchun qayta ishga tushadi.

Mini-test

for (n in 1..5) { if (n == 3) break; print(n) } nima chiqaradi?

n == 3 bo'lganda sikl to'xtaydi, 3 chop etilmaydi.

for va while: qaysi birini tanlaymiz?

for

Takrorlash soni oldindan ma'lum: for (i in 1..10)
VS

while

Takrorlash soni noma'lum, shart bo'yicha: while (qoldiq > 0)

Soni ma'lum bo'lsa for, shart bo'yicha bo'lsa while qulay.

Siklni tanlash bosqichlari

1. Oraliq bormi?

Sonlar chegarasi ma'lum bo'lsa for ishlating.

2. Shart bormi?

Qachon to'xtash noma'lum bo'lsa while.

3. Kamida 1 marta?

Tana kamida bir marta ishlashi kerak bo'lsa do-while.
