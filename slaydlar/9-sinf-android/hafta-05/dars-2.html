Funksiya yo'li

Birinchi funksiya


fun hello() {
    println("Hello Kotlin")
}

fun main() {
    hello()
    hello()
}
Funksiya ikki marta chaqirilgani uchun xabar ikki marta chiqadi. Bir kodni qayta yozmaslik funksiyaning asosiy foydasi.

Parametrlar

Funksiyaga ma'lumot uzatish

Parametr va argument

Parametrli funksiya


fun showMessage(message: String) {
    println(message)
}

fun displayUser(name: String, age: Int) {
    println("Name: $name  Age: $age")
}

fun main() {
    showMessage("Salom, Kotlin!")
    displayUser("Tom", 36)
}
Argumentlar parametrlar tartibida beriladi: avval name, keyin age. Turi mos kelmasa kompilyator xato beradi.

Mini-test

fun f(n: Int) { n = n * 2 } nega xato?

Funksiya parametrlari faqat o'qish uchun.
03

Standart va nomlangan

Default qiymat va named argument

Standart qiymat yo'li

Default va named argument


fun displayUser(name: String, age: Int = 18, position: String = "Intern") {
    println("$name, $age yosh, $position")
}

fun main() {
    displayUser("Bob")
    displayUser("Tom", position = "Manager", age = 28)
}
displayUser("Bob") ishlaydi: age va position standart qiymat oladi. Nomlangan argumentlarni tartibdan qat'i nazar yozish mumkin.

Funksiya yozish bosqichlari

1. Nom va vazifa

Funksiya nima qilishini aniqlab, fun nom() yozing.

2. Parametrlar

3. Chaqirish

Pastga bosing: qoidalar

Argument qoidalari

  1. Nomlanmagan argumentlar parametrlar tartibida beriladi.
  2. Birinchi nomlangan argumentdan keyin hammasi nomlangan bo'ladi.
  3. Standart qiymatli parametrni tushirib qoldirish mumkin.

Funksiyaga o'tkazamiz


println("Salom, Tom!")
println("Salom, Bob!")

Funksiyaga o'tkazamiz


fun salom(ism: String) {
    println("Salom, $ism!")
}
salom("Tom")
salom("Bob")

O'rtaFoydalanuvchi ma'lumoti: displayUser(name: String, age: Int = 18) funksiyasini yozing. Uni "Bob" va "Tom", 28 bilan chaqiring.
