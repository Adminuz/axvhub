Sinfdan obyekt

Person sinfi


class Person {
    var name = "Undefined"
    var age = 18
}

fun main() {
    val tom = Person()
    println(tom.name)
    tom.name = "Tom"
    tom.age = 37
    println("${tom.name} ${tom.age}")
}
Obyekt yaratishda new kerak emas: sinf nomi qavs bilan chaqiriladi. Xossaga obyekt.xossa orqali murojaat qilinadi.

Metodni chaqirish

Person metodlari


class Person {
    var name = "Undefined"
    var age = 18

    fun sayHello() {
        println("Hello, my name is $name")
    }
    fun personToString(): String = "$name, $age yosh"
}

fun main() {
    val tom = Person()
    tom.name = "Tom"
    tom.sayHello()
    println(tom.personToString())
}
Metod ichida name va age ga tom. yozmasdan murojaat qilinadi: ular shu obyektniki.

Konstruktorlar

Primary, secondary va init

Konstruktor tanlash

Primary va secondary


class Person(val name: String, var age: Int) {
    init {
        println("Obyekt yaratildi: $name")
    }
    constructor(name: String) : this(name, 18) {
        println("Yosh berilmadi, 18 olindi")
    }
}

fun main() {
    val tom = Person("Tom", 37)
    val bob = Person("Bob")
}
Sinfda faqat bitta primary konstruktor bo'ladi, secondary esa bir nechta bo'lishi mumkin; primary bor bo'lsa har biri this(...) bilan unga bog'lanadi.

Pastga bosing: yaratilish tartibi

Obyekt yaratilish tartibi

  1. Person(...) chaqiriladi, mos konstruktor tanlanadi.
  2. Secondary bo'lsa, u this(...) orqali primary ga o'tadi.
  3. init bloki ishlaydi, so'ng konstruktor tanasi bajariladi.
