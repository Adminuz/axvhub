Bashorat qiling

val a = 7; val b = 3
println("$a + $b") nima chiqaradi?

Har bir o‘zgaruvchi alohida qo‘yildi. Yig‘indi uchun ${a + b} kerak.

Turlarni aylantirish


val matn1 = "45"
val matn2 = "12"
val son1 = matn1.toInt()

println(son1 + son2)       // 57
println(matn1 + matn2)     // 4512 - matnlar ulandi
