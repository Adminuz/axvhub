Qadam-baqadam: telefonni tayyorlash

3. Kabel bilan ulash

4. Run

Android Studio telefonni ADB drayverlari orqali taniydi va ilovani unga yuklaydi.

Logcat oynasi (namuna)

Logcat
D/MainActivity: Ilova ishga tushdi
D/Hisoblash: Natija: 5
E/Xatolik: Nolga bo'lish: / by zero

Harf xabar darajasini bildiradi: D (Debug), E (Error).

Log.d va Log.e


import android.util.Log

fun natijaHisoblash(a: Int, b: Int) {
    try {
        val natija = a / b
        Log.d("Hisoblash", "Natija: $natija")
    } catch (e: Exception) {
        Log.e("Xatolik", "Nolga bo'lishga urinish: ${e.message}")
    }
}
Log.d: oddiy axborotLog.e: xato
