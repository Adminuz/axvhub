01

Android Studio muhiti

Google va JetBrains hamkorligidagi mukammal IDE

Android Studio imkoniyatlari

Intellektual kod muharriri

Kotlin va Java kodlarini yozishda avtomatik to'ldirish, xatolarni ko'rsatish va refaktoring.

Layout Editor

XML va Jetpack Compose interfeyslarini real vaqtda ko'rib, vizual loyihalash.

Asosiy ishchi oynalar

Project Explorer: Loyihaning barcha papkalari va fayllar daraxti.
Editor (Muharrir): Kod yoziladigan va dizayn chiziladigan markaziy oyna.
Logcat: Telefondagi barcha tizim xabarlari va nosozliklarni (crash) ko'rsatuvchi konsol.
Gradle: Loyihani yig'ish va kutubxonalarni boshqarish paneli.
02

Android SDK arxitekturasi

Software Development Kit: 3 ta asosiy ustun

Android SDK nima?

Dasturiy asboblar to'plami

Kodni kompilyatsiya qilish, testdan o'tkazish va telefonda ishga tushirish vositalari.

SDK operatsion tizim bilan muloqot qilish imkonini beradi.

3 ta asosiy tarkibiy qism:

1. SDK Platforms (API versiyalar)

2. SDK Platform-Tools (ADB)

3. SDK Build-Tools (aapt2, d8)

1. SDK Platforms

Tizim kutubxonalari

Har bir Android versiyasi (Android 14 API 34, Android 15 API 35) uchun alohida android.jar to'plami.

SDK Manager

Dasturchi yangi Android versiyalarini SDK Manager oynasi orqali bir tugma bilan yuklab oladi.

03

Platform-Tools: ADB ko'prigi

Android Debug Bridge bilan kompyuterdan boshqarish

ADB nima?

Mijoz-Server ko'prigi

Kompyuter va telefon o'rtasida USB yoki Wi-Fi orqali ma'lumot almashuvchi universal asbob.

Diagnostika va nazorat

Ilovani o'rnatish, tizim loglarini o'qish va terminal orqali buyruqlar berish.

Asosiy ADB buyruqlari

adb devices

Kompyuterga ulangan barcha faol qurilmalar va emulyatorlar ro'yxatini chiqaradi.

adb install app.apk

Ko'rsatilgan ilovani kompyuterdan to'g'ridan-to'g'ri smartfonga o'rnatadi.

adb logcat

Telefon ichidagi barcha xabarlar va xatoliklarni oqim sifatida ko'rsatadi.

04

SDK Build-Tools

Kodni ilovaga aylantiruvchi yig'ish zavodi

aapt2 va d8 kompilyatorlari

aapt2

Android Asset Packaging Tool 2. Barcha XML maketlar, ranglar va rasmlarni tekshirib, binar shaklga paketlaydi.

d8 / r8

Java baytkodini Android Runtime tushunadigan .dex baytkodiga o'tkazadi va keraksiz kodlarni tozalaydi.

Loyiha qanday yig'iladi?

1. Kod kompilyatsiyasi: Kotlin/Java kodi baytkodga aylanadi.
2. Resurslar (aapt2): XML fayllar va rasmlar binar paketlanadi.
3. DEX ga o'tish (d8): Baytkod .dex formatiga o'tkaziladi.
4. Paketlash: Barcha qismlar bitta APK yoki AAB fayliga birlashtiriladi.

Amaliy topshiriq 15 daqiqa

Oson Android SDK ning 3 ta asosiy tarkibiy qismini daftaringizga yozing.
O'rta adb devices va adb logcat buyruqlari nima vazifa bajarishini tushuntiring.
Qiyin aapt2 va d8 vositalari kodni ilovaga aylantirishdagi rolini asoslang.
