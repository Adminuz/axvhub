02

Linux Kernel va HAL

Apparat ta'minoti bilan to'g'ridan-to'g'ri aloqa

1-qatlam: Linux Kernel

Resurslar boshqaruvi

Virtual xotira (RAM) boshqaruvi, CPU vaqtini rejalashtirish va quvvat tejash.

Drayverlar va xavfsizlik

Kamera, Wi-Fi, audio drayverlari va ilovalarni UID orqali izolyatsiyalash.

2-qatlam: Hardware Abstraction Layer (HAL)

Apparatni yashirish qatlami

Turli ishlab chiqaruvchilar (Samsung, Xiaomi, Sony) har xil apparat qismlaridan foydalanadi.

HAL Java kodiga yagona standart C/C++ interfeysini beradi.

Dasturchiga qulaylik:

Bitta Camera API kodi yoziladi va u barcha telefon kameralarida birdek ishlaydi.

03

ART va Native kutubxonalar

Kodning mashina tiliga aylanish mexanizmi

Native C/C++ kutubxonalari

SQLite

Ilova ichida ishlaydigan engil va tezkor reliesion ma'lumotlar bazasi.

Surface Manager

2D va 3D grafika qatlamlarini ekranda silliq birlashtirib chizish.

Media Framework

MP3, MP4, AAC va boshqa audio-video formatlarni ijro etish va yozish.

Dalvik va ART taqqoslashi

Dalvik (JIT)

Android 4.4 gacha bo'lgan eski tizim.

Kodni ilova ochilgan paytda (Just-in-Time) mashina tiliga o'giradi.

Ilovalar sekinroq ochilar edi.

VS

ART (AOT)

Android 5.0 dan boshlab zamonaviy tizim.

Kodni ilova o'rnatilayotganda (Ahead-of-Time) to'liq tayyorlab qo'yadi.

Bir zumda ochiladi, batareyani tejaydi.

04

Java API Framework

Dasturchilar ishlatadigan asosiy tizim xizmatlari

Frameworkning asosiy xizmatlari

Activity Manager

Ilovalarning hayotiy sikli (Lifecycle), ekranning ochilishi va orqaga qaytish steki.

View System

Tugmalar (Button), matnlar (TextView), rasmlar (ImageView) va ro'yxatlar.

Framework xizmatlari (davomi)

Notification Manager

Yuqori panelda foydalanuvchiga muhim bildirishnomalarni ko'rsatish.

Content Providers

Ilovalar o'rtasida ma'lumot almashish (masalan, telefon kontaktlarini o'qish).

05

Xavfsizlik: Application Sandbox

Har bir ilova alohida izolyatsiyalangan muhitda

Sandbox qanday ishlaydi?

UID izolyatsiyasi

Har bir yangi ilovaga alohida Linux foydalanuvchi identifikatori (UID) beriladi.

Hech bir ilova boshqasining xotirasini yoki shaxsiy fayllarini o'qiy olmaydi.

Ruxsatlar tizimi (Permissions):

Agar ilova kameraga yoki mikrafonga kirmoqchi bo'lsa, tizim foydalanuvchidan rasman ruxsat so'raydi.

06

Ma'lumotlarni saqlash

Qayerda va qanday usulda saqlaymiz?

Androidda ma'lumot saqlash turlari

SharedPreferences / DataStore

Kichik sozlamalar: til, qorong'u rejim, kirish seansi (Key-Value).

SQLite va Room

Katta hajmdagi reliesion jadvallar, qidiruv va filtrlash imkoniyati.

Firebase Firestore

Internet orqali real vaqt rejimida barcha qurilmalar bilan sinxronlanadigan bulutli baza.
