01

Loyiha yaratish qadamlari

New Project oynasidagi muhim parametrlar

Parametrlarni to'ldirish

1. Shablon: Empty Views Activity (klassik XML + Kotlin modeli).
2. Name & Package: SalomDunyo va uz.edu.salomdunyo.
3. Language: Kotlin (zamonaviy rasmiy til).
4. Minimum SDK: API 24: Android 7.0 (qurilmalarning 96% qamraydi).
02

XML maket bilan ishlash

Layout Editor va Split rejimi imkoniyatlari

Split rejimi — eng qulay usul

Chapda kod, o'ngda ekran

XML kodiga o'zgartirish kiritishingiz bilan, o'ng tarafdagi virtual telefon ekranida natija bir zumda ko'rinadi.

Fayl manzili: res/layout/activity_main.xml.

Tezkor tugmalar:

Design, Split va Code rejimlarini oynaning yuqori o'ng burchagidagi tugmalar orqali almashtirasiz.

TextView komponenti kodi


<TextView
    android:id="@+id/tvHello"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Salom, Dunyo!"
    android:textSize="26sp"
    android:textColor="@color/primary"
    android:textStyle="bold" />
Matn o'lchami faqat sp (scale-independent pixels) birligida belgilanadi!
03

strings.xml bilan ishlash

Extract String Resource amaliyoti

Nega sariq ogohlantirish chiqadi?

Hardcoded string xatosi

Matnni to'g'ridan-to'g'ri XML ichida yozish yaxshi amaliyot emas.

Ilova bir nechta tilga tarjima qilinishi kerak bo'lganda chalkashlik yuzaga keladi.

Alt + Enter sehrli tugmasi

Kursorni matn ustiga qo'yib Alt + Enter bosiladi.

Matn avtomatik ravishda res/values/strings.xml fayliga o'tadi.

04

MainActivity.kt siri

Kod qanday qilib XML dizayn bilan bog'lanadi?

setContentView funksiyasi


class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
    }
}

setContentView nima qiladi?

U Kotlin kodini activity_main.xml bilan biriktirib, barcha tugma va matnlarni ekranga chizib beradi.

05

Gradle Build mexanizmi

"Run" bosilganda nima sodir bo'ladi?

Kodni yig'ish zanjiri

1. Kompilyatsiya: Kotlin kodi baytkodga o'giriladi.
2. aapt2: XML fayllar va rasmlar binar formatga paketlanadi.
3. d8: Baytkod Android tushunadigan .dex ga aylanadi.
4. APK yig'ilishi: Hamma qismlar bitta APK faylga birlashadi.
5. ADB orqali ochish: Ilova telefonga o'rnatilib, ekranda ochiladi.

Qiyin Alt + Enter orqali matnni strings.xml fayliga o'tkazing.
