Skript fayli anatomiyasi

Har qatorni bosing yoki ustiga olib boring.

Birinchi skript


#!/bin/bash
# salom.sh - birinchi skript
ISM="Ali"
echo "Salom, $ISM!"
echo "Papka: $PWD"
echo "Foydalanuvchi: $USER"
$PWD va $USER shell o'zgaruvchilari (qo'llanma, 1.1-1.3 jadvallar).

Skriptni ishga tushirish: 4 qadam

1. Yozing

nano salom.sh bilan faylni yarating.

2. Ruxsat bering

chmod +x salom.sh (yoki chmod 755 salom.sh).

3. Ishga tushiring

./salom.sh: nuqta-slesh joriy papkani bildiradi.

4. Natijani tekshiring

Chiqishni ko'ring, kerak bo'lsa nano da tuzating.

Ishga tushirish va tipik xato

Terminal
$ ./salom.sh
bash: ./salom.sh: Permission denied
$ chmod +x salom.sh
$ ./salom.sh
Salom, Ali!
Papka: /home/ali
Foydalanuvchi: ali
$ bash salom.sh
Salom, Ali!
Permission denied chiqsa: faylda x (execute) ruxsati yo'q. 1-haftadagi chmod ni eslang.
02

O'zgaruvchilar

Qiymatni nom bilan saqlaymiz

O'zgaruvchi = yorlig'i bor quti

Quti ustidagi yorliq - nom, ichidagi narsa - qiymat. $ qutini ochadi.

Tenglik atrofida bo'sh joy yo'q


ISM = "Ali"
echo "Salom, $ISM"

Natija: ISM: command not found

Tenglik atrofida bo'sh joy yo'q


ISM="Ali"
echo "Salom, $ISM"

Natija: Salom, Ali

Uch xil o'zgaruvchi (qo'llanma)

Local

bosing

Faqat joriy shellda. NOM="Ali". Quyi jarayonga o'tmaydi.

Environment

bosing

Quyi jarayonlarga ham ochiq: export PORT=8080. Ko'rish: printenv, env.

Shell (system)

bosing

Shellning o'zi yaratadi, katta harfda: USER, HOME, PWD.

Tirnoqlar: farq katta

$ ishlaydi

ISM="Ali"
echo "Salom, $ISM"
# Salom, Ali

Matn o'zgarmaydi

ISM="Ali"
echo 'Salom, $ISM'
# Salom, $ISM

Buyruq natijasini o'zgaruvchiga


YIL=$(date +%Y)
echo "Yil: $YIL"
FAYLLAR=$(ls | wc -l)

Pastga bosing: ${} haqida.

Qo'shimcha: ${NOM}

SON=5
echo "$SONta"      # bo'sh: SONta degan o'zgaruvchi yo'q
echo "${SON}ta"    # 5ta
03

Argument va kiritish

Skript tashqaridan ma'lumot oladi

Argumentlar: skriptga berilgan qiymatlar

arg.sh


#!/bin/bash
echo "Skript nomi: $0"
echo "1-argument: $1"
echo "2-argument: $2"
echo "Argumentlar soni: $#"
echo "Hammasi: $@"
Terminal
$ ./arg.sh Ali 16
Skript nomi: ./arg.sh
1-argument: Ali
2-argument: 16
Argumentlar soni: 2
Hammasi: Ali 16

Kiritish va chiqarish: echo, printf, read

echo

Matnni qatorga chiqaradi. echo -n qator o'tkazmaydi.

printf

Formatli chiqish: %s matn, %d butun son, \n yangi qator.

read

Klaviaturadan (stdin) qiymat oladi. -p savol matni, -s yashirin.

kirish.sh


#!/bin/bash
read -p "Ismingiz: " ISM
read -p "Yoshingiz: " YOSH
printf "%s, siz %d yoshdasiz\n" "$ISM" "$YOSH"
printf "Keyingi yil: %d\n" $((YOSH + 1))
$((...)) ichida arifmetik amal bajariladi. Keyingi darsda batafsil.

Tezkor bilim sinovi

./hisob.sh 5 9 2 ishga tushirilganda $# nimaga teng?

$# argumentlar sonini beradi: 5, 9 va 2 - jami 3 ta. $0 esa skript nomi.

Odatiy xatolar

  • NOM = "Ali": tenglik atrofida bo'sh joy.
  • Shebang yo'q yoki #! /bin/bsh kabi imloviy xato.
  • chmod +x unutilgan: Permission denied.
  • Bitta tirnoq ichida $NOM kutish.
  • O'zgaruvchini qo'shtirnoqsiz ishlatish: bo'sh joyli qiymat bo'laklanadi.
