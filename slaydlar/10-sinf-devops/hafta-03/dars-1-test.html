10 ta savol · taxminan 8 daqiqa

10-sinfDevOps3-hafta

Savol 1/10

Git da branch aslida nima?

Branch yaratish fayllarni nusxalamaydi, shunchaki yangi havola hosil qiladi.

Savol 2/10

git branch natijasida joriy branch qanday belgilanadi?

Masalan * feature-contact, qolganlari oddiy yoziladi.

Savol 3/10

git branch -d bilan git branch -D ning farqi nimada?

Birlashtirilmagan ishni yo'qotmaslik uchun -d xavfsiz hisoblanadi.

Savol 4/10

Fast-forward merge qachon sodir bo'ladi?

Git shunchaki main ko'rsatkichini oldinga siljitadi.

Savol 5/10

3-way merge natijasida nima hosil bo'ladi?

main ham, feature ham o'zgargan bo'lsa Git Merge commit yaratadi.

Savol 6/10

Konflikt belgilarida <<<<<<< HEAD va ======= oralig'idagi kod nimani bildiradi?

======= dan >>>>>>> gacha esa qo'shilayotgan branch kodi turadi.

Savol 7/10

Lokal repozitoriyaga GitHub manzilini bog'lash buyrug'i qaysi?

origin — masofaviy manzilning standart nomi.

Savol 8/10

git push -u origin main dagi -u nimani o'rnatadi?

Keyingi safar shunchaki git push va git pull yetarli bo'ladi.

Savol 9/10

git pull aslida qaysi ikki amalning birikmasi?

Pull masofaviy yangiliklarni yuklab, darhol lokal branchga birlashtiradi.

Savol 10/10

feature-login ni main ga qo'shishning to'g'ri ketma-ketligi qaysi?

Avval qabul qiluvchi branchga o'tiladi, keyin birlashtirish buyrug'i beriladi.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: branch tushunchasi, merge turlari (Fast-forward, 3-way), konflikt belgilari, remote, push, pull.
