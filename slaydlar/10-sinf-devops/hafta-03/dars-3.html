IPv4 manzili anatomiyasi

Ommaviy vs Xususiy IP manzillar

Xususiy IP (RFC 1918)

192.168.x.x, 10.x.x.x, 172.16.x.x diapazonlari.

Faqat uy, ofis yoki data-center ichida ishlaydi.

Internetda to'g'ridan-to'g'ri ko'rinmaydi (mutlaqo bepul).

Ommaviy IP (Public)

Global Internetda yagona va takrorlanmas manzil.

Veb-saytlar va tashqi serverlar uchun beriladi.

Internet provayderlari tomonidan pullik ijaraga beriladi.

bosing

03

Tarmoq diagnostikasi

ping, traceroute, ss va curl amaliyoti

Traceroute qanday ishlaydi?

Diagnostika zanjiri

1. ping 8.8.8.8

Internetga jismoniy ulanish va kechikishni (RTT) tekshirish.

2. tracepath site.uz

Paket qaysi oraliq routerda to'xtab qolayotganini aniqlash.

3. curl -I URL

Veb-serverning HTTP javob kodi (200, 502, 404) ni tekshirish.

Amaliy tarmoq buyruqlari


# Aloqani 4 ta paket bilan tekshirish
ping -c 4 1.1.1.1

# Veb-sayt sarlavhalari va status kodini ko'rish
curl -I https://github.com

# Ommaviy IP manzilni aniqlash
curl ifconfig.me
curl -I sahifani to'liq yuklamasdan faqat HTTP javobini oladi.

Tezkor bilim sinovi

192.168.1.0/24 tarmog'ida foydalanuvchilar kompyuterlariga berilishi mumkin bo'lgan maksimal xostlar soni nechta?

To'g'ri: 2^8 = 256. Network ID (.0) va Broadcast ID (.255) ayirilsa: 254 ta xost qoladi!
