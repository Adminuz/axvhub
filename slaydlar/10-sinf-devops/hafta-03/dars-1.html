Branchlarni birlashtirish

Merge turlari

Fast-forward Merge

Main branchda siz ajralganingizdan beri yangi kommit bo'lmagan.

Git shunchaki main ko'rsatkichini oldinga surib qo'yadi.

Qo'shimcha merge commit yaratilmaydi.

3-Way Merge (Haqiqiy birlashuv)

Ikkala branchda ham parallel ravishda yangi kommitlar kiritilgan.

Git ikkita ota kommitga ega bo'lgan yangi «Merge commit» hosil qiladi.

Tarixda tarmoqlanish va birlashish yaqqol aks etadi.

Merge Conflict (Mojaro) anatomiyasi

Konfliktni hal qilish algoritmi

1. Faylni ochish

Konfliktli faylni matn muharririda oching.

2. To'g'ri kodni qoldirish

Keraksiz qatorlarni va <<<, ===, >>> belgilarini o'chiring.

3. Commit qilish

git add [fayl] va git commit bilan yakunlang.

03

Masofaviy omborlar (Remote)

GitHub, GitLab va jamoaviy hamkorlik: push va pull

Lokal va Masofaviy ombor aloqasi

Masofaviy buyruqlar

git clone

bosing

GitHub'dagi butun loyihani tarixi bilan o'z kompyuteringizga to'liq ko'chiradi.

git push

bosing

Lokal commitlarni GitHub serveriga xavfsiz yuklaydi (yuklash).

git pull

bosing

Jamoaning yangi o'zgarishlarini GitHub'dan lokal omborga oladi (yangilash).

Amaliy buyruqlar sintaksisi


# Yangi branch ochish va unga o'tish
git switch -c feature-navbar

# Asosiy branchga birlashtirish
git switch main && git merge feature-navbar

# GitHub masofaviy omboriga yuklash
git push -u origin main
git switch -c buyrug'i git checkout -b ning zamonaviy va xavfsiz analogidir.

Tezkor bilim sinovi

Qaysi buyruq yangi branch yaratib, darhol unga o'tishni ta'minlaydi?

To'g'ri: 'git switch -c' (yoki 'checkout -b') yangi branch ochadi va avtomatik unga o'tadi!

Amaliy topshiriq 20 daqiqa

Osongit switch -c feature-test qiling va bitta fayl commit qiling.
O'rtamain ga qaytib, uni merge qiling va branchni o'chiring.
QiyinMerge conflict hosil qiling va uni qo'lda to'g'rilab muhrlang.
