03

Disk monitoringi: df va du

Qaysi bo'lim to'ldi va qaysi papka ko'p joy olyapti?

df va du buyruqlari taqqosi

df -h (Umumiy bo'sh joy)

Barcha ulangan disk bo'limlari hajmini ko'rsatadi.

Qaysi disk qancha foiz to'lganini bir zumda bilish.

Misol: df -h /

du -sh (Katalog sarfi)

Aniq bitta papka yoki fayl hajmini hisoblaydi.

Haddan tashqari shishib ketgan papkalarni topish.

Misol: du -sh /var/log

04

Paket menejerlari (APT)

Dasturlarni repozitoriyalardan xavfsiz o'rnatish

APT ishlash arxitekturasi

APT yordamida dastur o'rnatish

1. Indekslarni yangilash

sudo apt update — eng so'nggi ro'yxatni yuklaydi.

2. O'rnatish

sudo apt install -y htop — dastur va bog'liqliklarni o'rnatadi.

3. Tozalash

sudo apt autoremove — keraksiz qoldiqlarni yo'qotadi.

Swap xotirasi xavfsizlik yostig'i

Amaliy boshqaruv buyruqlari


# Tizimdagi bo'sh disk maydonini ko'rish
df -h /

# Eng katta kataloglarni aniqlash
sudo du -sh /var/* | sort -h

# Dasturni to'liq (sozlamalari bilan) o'chirish
sudo apt purge nginx
df -h natijasida Use% ustunini doimo nazorat qiling.

Tezkor bilim sinovi

Qaysi buyruq dasturni uning barcha konfiguratsiya fayllari bilan birga butunlay yo'q qiladi?

To'g'ri: 'purge' barcha konfiguratsiyalarni tozalaydi, 'remove' esa faqat dastur fayllarini o'chiradi.

Amaliy topshiriq 20 daqiqa

Osondf -h va lsblk orqali disklaringizni tekshiring.
O'rtadu -sh ~/* | sort -h bilan katta papkalarni aniqlang.
Qiyinsudo apt update && sudo apt install -y ncdu qilib xotirani tahlil qiling.
