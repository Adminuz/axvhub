03

Asosiy buyruqlar zanjiri

git init, status, add va commit amalda

Commit qilishning 3 qadami

1. Kod yozish

Fayllarni o'zgartirasiz. git status qizil rangda ko'rsatadi.

2. git add

git add . orqali o'zgarishlarni yashil (Staged) holatga o'tkazasiz.

3. git commit

git commit -m "feat: yangi sahifa" bilan tarixga muhrlaysiz.

04

.gitignore va xavfsizlik

Git omboriga tushmasligi shart bo'lgan fayllar

.gitignore filtrlash qoidasi

Amaliy Git buyruqlari


# Repozitoriy ochish va holatni tekshirish
git init
git status

# O'zgarishlarni qo'shish va commit qilish
git add .
git commit -m "feat: birinchi commit"

# Tarixni bir qatorda ixcham ko'rish
git log --oneline
git log --oneline katta loyihalarda tarixni tez ko'rish uchun eng qulay usuldir.

Tezkor bilim sinovi

O'zgartirilgan fayllarni Staging Area (tayyorgarlik maydoni) ga o'tkazish uchun qaysi buyruq ishlatiladi?

To'g'ri: 'git add' fayllarni Staging Area ga tayyorlaydi, 'git commit' esa ularni tarixga yozadi.

Amaliy topshiriq 20 daqiqa

Osongit init bilan repozitoriya yarating va README.md qo'shing.
O'rtagit commit -m "feat: birinchi sahifa" qilib, git log ni ko'ring.
Qiyin.gitignore fayliga *.log qo'shib, filtrlashni sinang.
