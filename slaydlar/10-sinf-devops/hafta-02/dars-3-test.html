6-dars testi

10 ta savol · taxminan 8 daqiqa

10-sinfDevOps2-hafta

Savol 1/10

Versiya boshqaruvi tizimi (VCS) nimani amalga oshiradi?

VCS tarixni saqlaydi, jamoada parallel ishlashga imkon beradi.

Savol 2/10

git init buyrug'i nima hosil qiladi?

git init joriy katalogda bo'sh Git repozitoriyasi yaratadi.

Savol 3/10

Fayllar git add dan keyin Git ning qaysi hududiga tushadi?

add — Staging Area ga, commit — Repository ga yozadi.

Savol 4/10

Har bir commit qaysi noyob identifikator bilan belgilanadi?

Commit hash, muallif, sana va izohga ega bo'ladi.

Savol 5/10

Yangi fayl yaratildi. git status uni qanday ko'rsatadi?

Git yangi faylni git add qilinmaguncha kuzatmaydi.

Savol 6/10

Commitlarni har birini bir qatorda ixcham ko'rish buyrug'i qaysi?

git log tarixni, --oneline esa ixcham ko'rinishni beradi.

Savol 7/10

git diff nimani ko'rsatadi?

Qo'shilgan qatorlar +, o'chirilganlar - bilan ko'rsatiladi.

Savol 8/10

git config --global user.name va user.email nega kiritiladi?

Bu ma'lumotlar commit muallifi sifatida yoziladi.

Savol 9/10

.gitignore ichida *.log yozilgan. Qaysi fayl e'tiborsiz qoldiriladi?

*.log kengaytmasi .log bo'lgan barcha fayllarga mos keladi.

Savol 10/10

index.html ni tahrirladingiz va git commit -m "fix" qildingiz, git add qilmadingiz. Natija?

Commit faqat Staging Area dagi o'zgarishlarni saqlaydi.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: VCS va Git hududlari, git init/add/commit/log/diff, git config, .gitignore.
