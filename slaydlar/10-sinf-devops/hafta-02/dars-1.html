bosing

02

Oldingi va Fon rejimlari

Foreground va Background aloqasi

Jarayonni fonga o'tkazish algoritmi

1. Jarayonni to'xtatish

Terminalda Ctrl + Z bosing — jarayon «Stopped» bo'ladi.

2. Fonda davom ettirish

bg buyrug'ini bering — jarayon fonda qayta yuguradi.

3. Terminalga qaytarish

fg %1 orqali uni istalgan payt yana oldingi rejimga oling.

03

Signallar va to'xtatish

SIGTERM (15) va SIGKILL (9) farqi

SIGTERM vs SIGKILL

SIGTERM (Standart kill)

Jarayonga o'zini toza yopish taklif qilinadi.

Fayllarni saqlaydi, xotirani tozalaydi, soketlarni yopadi.

Buyruq: kill [PID]

SIGKILL (Majburiy kill -9)

Linux yadrosi jarayonni so'rovsiz bir zumda xotiradan o'chiradi.

Qotib qolgan dasturlar uchun oxirgi chora.

Buyruq: kill -9 [PID]

Asosiy Unix signallari

04

Systemd va systemctl

Serverdagi doimiy xizmatlarni (daemons) boshqarish

Systemd xizmatlar daraxti

systemctl boshqaruv sintaksisi


# Xizmatni yoqish va to'xtatish
sudo systemctl start nginx
sudo systemctl stop nginx

# Xizmat holatini tekshirish
systemctl status nginx

# Server yoqilganda avtomat ishga tushishi (Autostart)
sudo systemctl enable nginx
status buyrug'i xizmat qulaganda oxirgi xatolik loglarini ham ko'rsatadi.

Tezkor bilim sinovi

Qaysi buyruq server qayta yuklanganda (reboot) xizmatning avtomatik ishga tushishini ta'minlaydi?

To'g'ri: 'enable' xizmatni autostart ga qo'shadi, 'start' esa uni faqat joriy sessiyada yoqadi.
