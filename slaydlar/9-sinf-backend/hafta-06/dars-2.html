def bol(a, b):
    try:
        natija = a / b
    except ZeroDivisionError:
        return "Xato: 0 ga bo'lib bo'lmaydi!"
    except TypeError:
        return "Xato: sonlar kerak."
    else:
        return natija
    finally:
        print("hisob tugadi")

print(bol(10, 2))        # hisob tugadi / 5.0
print(bol(5, 0))         # hisob tugadi / Xato: 0 ga bo'lib bo'lmaydi!
print(bol("a", 2))       # hisob tugadi / Xato: sonlar kerak.
Hamma narsani bitta except: bilan ushlamang: dasturdagi haqiqiy xato yashirinib qoladi va uni topish qiyinlashadi.

def yosh_ol():
    while True:
        matn = input("Yoshingiz: ")
        try:
            yosh = int(matn)
            if yosh < 0:
                raise ValueError("manfiy")
            return yosh
        except ValueError:
            print("Xato: 0 yoki undan katta butun son kiriting.")

yosh = yosh_ol()
print("Siz kiritdingiz:", yosh)
raise ValueError(...) va int("abc") ikkalasi ham ValueError: shuning uchun bitta except ikkala holatni ushlaydi.

Xavfsiz kalkulyator

  1. Ikkita son so'rang va bo'ling; ValueError va ZeroDivisionError ni alohida ushlang.
  2. Natijani else da chiqaring, «tugadi» xabarini finally da chiqaring.
  3. To'g'ri son kiritilguncha qayta so'raydigan son_ol() funksiyasini yozing.
