Yozuvlar funksiyalari


def yozuv_qosh(matn, nom="kundalik.txt"):
    with open(nom, "a", encoding="utf-8") as f:
        f.write(matn + "\n")

def yozuvlar(nom="kundalik.txt"):
    try:
        with open(nom, encoding="utf-8") as f:
            return f.read().splitlines()
    except FileNotFoundError:
        return []

yozuv_qosh("Python o'rgandim", "yangi.txt")
print(yozuvlar("yangi.txt"))   # ["Python o'rgandim"]
print(yozuvlar("yoq.txt"))     # []
Faylga yozishda ham xato bo'lishi mumkin (papka yo'q, ruxsat yo'q): PermissionError, OSError. Kerak bo'lsa ularni ham ushlang.
