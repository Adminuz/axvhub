01

match / case sintaksisi

1.46-rasm: Qiymat, variantlar va boshqa holatlar (_)

match / case tuzilishi

Dastur menyusi kodi (1.47-rasm)

tanlov = int(input("Tanlovni kiriting (1-3): "))

match tanlov:
    case 1:
        print("Dastur boshlandi")
    case 2:
        print("Sozlamalar ochildi")
    case 3:
        print("Dastur yopildi")
    case _:
        print("Noto'g'ri tanlov")
02

Hafta kunini tanlash

1.48-rasm: 1 dan 7 gacha raqamlar bo‘yicha tanlov

Hafta kunlari dasturi kodi

kun = int(input("Hafta kunini kiriting (1-7): "))

match kun:
    case 1: print("Dushanba")
    case 2: print("Seshanba")
    case 3: print("Chorshanba")
    case 4: print("Payshanba")
    case 5: print("Juma")
    case 6: print("Shanba")
    case 7: print("Yakshanba")
    case _:
        print("Xato! 1–7 oralig'ida kiriting")
03

Rasmiy amaliy topshiriqlar

3 ga karrali sonlar va 12 ta oy nomlari

Topshiriq 2: 3 ga karrali sonlar süzgichi

3 ga karralilar: for va while

for sikli bilan

n = 20
for i in range(1, n + 1):
    if i % 3 == 0:
        print(i, end=" ")
# 3 6 9 12 15 18

while sikli bilan

n = 20
i = 1
while i <= n:
    if i % 3 == 0:
        print(i, end=" ")
    i += 1
# 3 6 9 12 15 18

Topshiriq 3: 12 oy va fasllar guruhi

Oy nomlari dasturi (match/case)

oy = int(input("Oy raqamini kiriting (1-12): "))

match oy:
    case 1: print("Yanvar")
    case 2: print("Fevral")
    case 3: print("Mart")
    case 4: print("Aprel")
    case 5: print("May")
    case 6: print("Iyun")
    # ... qolgan oylar
    case _:
        print("Xato! 1–12 oralig'ida kiriting")

Tezkor sinov

Quyidagi match/case blokida x = 7 bo‘lsa nima chiqadi?

x = 7
match x:
    case 1 | 3 | 5: print("Toq 1")
