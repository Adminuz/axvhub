01

Ma’lumotlar toifalari

Xotirada ma'lumotlar qanday shaklda saqlanadi?

Pythonda 4 ta asosiy sodda toifa

Toifani tekshirish: type()

Python o‘zgaruvchi toifasini unga berilgan qiymatdan avtomatik aniqlaydi

# Har xil toifadagi ma'lumotlar
x = 100
pi = 3.14
ism = "Ali"
faol = True

print(type(x))    # <class 'int'>
print(type(pi))   # <class 'float'>
print(type(ism))  # <class 'str'>
print(type(faol)) # <class 'bool'>
02

Arifmetik amallar

Standart operatorlar va amallar ustunligi

Asosiy arifmetik operatorlar

+ Qo‘shish

15 + 5 → 20

- Ayirish

20 - 7 → 13

* Ko‘paytirish

6 * 8 → 48

/ Bo‘lish

8 / 2 → 4.0

E'tibor bering: / amali har doim float natija beradi!
03

Butun bo‘lish va Qoldiq

// va % operatorlarining sirlari

91 sonini bo‘lish tahlili

// va % operatorlari amalda

# Butun bo'lish (//)
print(7 // 3)   # 2
print(15 // 4)  # 3
print(20 // 5)  # 4

# Qoldiqni topish (%)
print(8 % 3)    # 2 (chunki 8 = 3 * 2 + 2)
print(15 % 4)   # 3 (chunki 15 = 4 * 3 + 3)
print(10 % 2)   # 0 (qoldiq 0 bo'lsa juft son!)

Darajaga oshirish: **

Matematikadagi xy amali Pythonda ** bilan ifodalanadi

2 ** 3

8

2 ning kubi (2 × 2 × 2)

5 ** 2

25

5 ning kvadrati (5 × 5)

10 ** 4

10000

10 ning 4-darajasi

Amallar ustunligi tartibi

Keys: Sekundlarni daqiqaga aylantirish

Vaqt hisobi kodi

# Vaqtni ajratish algoritmi
jami_sekund = 195

daqiqa = jami_sekund // 60
qoldiq_sekund = jami_sekund % 60

print("Natija:", daqiqa, "daqiqa va", qoldiq_sekund, "sekund")
# Konsolda chiqadi:
# Natija: 3 daqiqa va 15 sekund

Ko‘p uchraydigan xatolar

Xato: Nolga bo‘lish (ZeroDivision)

# Xato
x = 10 / 0
# ZeroDivisionError: division by zero

Dasturda sonni hech qachon nolga bo‘lib bo‘lmaydi!

Xato: Matn va sonni qo‘shish

# Xato
y = "Yosh: " + 15
# TypeError: can only concatenate str to str

Har xil toifadagi ma'lumotlarni to‘g‘ridan-to‘g‘ri qo‘shib bo‘lmaydi.

1. Oson

Tezkor sinov

Quyidagi kod konsolga nima chiqaradi?

print(20 // 6, 20 % 6)
Javob: 3 2 (chunki 20 = 6 * 3 + 2)
