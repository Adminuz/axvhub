03

Rasmiy amaliy loyihalar

"Tanishuv kartochkasi" va "Do‘kon kassasi"

Loyiha 1: "Tanishuv kartochkasi"

"Tanishuv kartochkasi" kodi

# 1. O'zgaruvchilarni e'lon qilish
ism = "Ali"
yosh = 15
kasb = "Dasturchi"

# 2. Bitta print ichida ekranga chiqarish
print("Ism:", ism, "| Yosh:", yosh, "| Kasb:", kasb)
f-string bilan: print(f"Ism: {ism} | Yosh: {yosh} | Kasb: {kasb}")

Loyiha 2: "Do‘kon kassasi" sxemasi

"Do‘kon kassasi" kodi

# 1. Narxlarni belgilash
non_narxi = 3000
sut_narxi = 12500.5

# 2. Jami summani hisoblash
jami = non_narxi + sut_narxi

# 3. Natijani chop etish
print("Jami to'lov:", jami, "so'm")
# Natija: Jami to'lov: 15500.5 so'm

Qiymatni yangilash: += operatori

To‘liq ko‘rinish

hisob = 50000
# 20 000 qo'shish
hisob = hisob + 20000
print(hisob)  # 70000

Qisqartirilgan ko‘rinish

hisob = 50000
# Qisqa va qulay
hisob += 20000
print(hisob)  # 70000

O‘zgaruvchilardagi xatolar

Xato: NameError

# Xato
print(shahar)
# NameError: name 'shahar' is not defined

Yaratilmagan o‘zgaruvchini ishlatib bo‘lmaydi!

Xato: SyntaxError

# Xato
talaba yoshi = 15
# To'g'ri:
talaba_yoshi = 15
