03

REPL va ilk dastur

Konsolda tezkor muloqot va print() funksiyasi

REPL nima? (Read-Eval-Print Loop)

Birinchi dastur: print()

Ekranga ma'lumot chiqarishning asosiy vositasi

# Matn chiqarish
print("Hello, World!")

# O'zbekcha salomlashuv
print("Salom, Muhammad al-Xorazmiy vorislari!")
Matn har doim qo‘shtirnoq "..." yoki birtirnoq '...' ichida yoziladi.

print() parametrlari: sep va end

# sep - qiymatlar orasidagi ajratuvchi
print("FastAPI", "PostgreSQL", "Docker", sep=" + ")
# Natija: FastAPI + PostgreSQL + Docker

# end - qator oxiridagi belgi (sukut bo'yicha yangi qator)
print("Yuklanmoqda...", end=" ")
print("Muvaffaqiyatli!")
# Natija: Yuklanmoqda... Muvaffaqiyatli!

Interaktiv rejim vs Faylda ishlash

REPL (>>>)

  • Tezkor sinov va tajribalar
  • Kod saqlanib qolmaydi
  • Yopilgach barcha ma'lumot o'chadi
  • Kichik hisob-kitoblar uchun qulay

Skript (main.py)

  • Katta va doimiy loyihalar
  • Kod diskda fayl sifatida saqlanadi
  • Versiyalar nazoratiga (Git) olinadi
  • Serverda ishga tushiriladi

Backend tizimida Python qayerda turadi?

Boshlang'ich dasturchilar xatosi

Xato: Katta harf bilan yozish

# Xato
Print("Salom")
# To'g'ri
print("Salom")

Python katta-kichik harflarni qat'iy farqlaydi!

Xato: Qo‘shtirnoqni unutish

# Xato: NameError
print(Salom)
# To'g'ri:
print("Salom")

Matnlar albatta qo‘shtirnoq ichida bo‘lishi lozim!
