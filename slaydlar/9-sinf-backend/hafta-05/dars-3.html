02

Murojaat va o‘zgartirish

d["key"], get(), yangilash va qo‘shish

Kalit orqali qiymat olish (1.81-rasm)


user = {"name": "Ali", "age": 15, "city": "Toshkent"}
print(user["name"])    # Ali
print(user["phone"])
        
KeyError: 'phone'
Kalit bo‘lmasa - xato, dastur to‘xtaydi.

Xatosiz yo‘l: get()

user["phone"]

Kalit yo‘q -> KeyError. Dastur shu joyda to‘xtaydi.

user.get("phone", "yo'q")

Kalit yo‘q -> "yo'q" qaytadi. Kod ishini to‘xtatmaydi.

Kalit aniq bor bo‘lsa [ ], bo‘lmasligi mumkin bo‘lsa get().

Yangilash va qo‘shish (1.82-rasm)


user = {"name": "Ali", "age": 15}

Yangilash va qo‘shish (1.82-rasm)


user = {"name": "Ali", "age": 15}
user["age"] = 23           # bor kalit: yangilanadi
user["phone"] = "+99890"   # yangi kalit: qo'shiladi
print(user)  # {'name': 'Ali', 'age': 23, 'phone': '+99890'}

d[key] = value: Python qanday qaror qiladi?

Bashorat qiling

d = {"a": 1, "b": 2}; d["a"] = 10; d["c"] = 3. len(d) nimaga teng?

"a" yangilandi (yangi kalit emas), "c" qo‘shildi: {'a': 10, 'b': 2, 'c': 3}.

if/else zanjiri o‘rniga dict (1.88-rasm)


texts = {"uzl": "Salom!", "rus": "Привет!", "en": "Hello!"}
til = "en"
print(texts[til])   # Hello!

Yangi til qo‘shish - bitta qator. Taqqoslash uchun pastga

Xuddi shu - if/else bilan


if til == "uzl":
    print("Salom!")
elif til == "rus":
    print("Привет!")
elif til == "en":
    print("Hello!")
Variant ko‘paysa, kod uzun va chalkash bo‘ladi.
03

Beshta tuzilma birga

«Talabalar ma’lumotlari» loyihasi

Qaysi ma’lumot - qaysi tuzilmada?

Loyiha qadam-baqadam

1. string va list

ism = "Ali"; familiya = "Valiyev"
fanlar = ["Matematika", "Informatika"]
fanlar.append("Fizika")

2. tuple va set

shaxsiy = (2011, "AB1234567")
baholar = sorted(set([5, 4, 5, 5, 3]))
# [3, 4, 5]

3. dict ga jamlash

talaba = {"toliq_ism": ism + " " + familiya,
          "fanlar": fanlar, "shaxsiy": shaxsiy,
          "baholar": baholar}
talaba["sinf"] = "9-sinf"

4. Natijani chiqarish

print("Talaba:", talaba["toliq_ism"])
print("Yil:", talaba["shaxsiy"][0])
print("Tel:", talaba.get("telefon", "kiritilmagan"))
