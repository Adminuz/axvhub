01

Tuple nima?

Tartibli, lekin o‘zgarmas elementlar to‘plami

Ta’rif (rasmiy qo‘llanma, 1.67-rasm)

Tuple - bu tartibli (ordered) elementlar to‘plami. Listga o‘xshaydi, lekin eng katta farqi: tuple o‘zgarmas (immutable).

talaba = ("Ali", "Valiyev", 2011)
print(talaba)        # ('Ali', 'Valiyev', 2011)
print(type(talaba))  # <class 'tuple'>

Daftar va muhrlangan hujjat

Qismlar ustiga sichqoncha olib boring yoki bosing.

Tuple yaratish (1.68-rasm)


fanlar = ("Matematika", "Fizika", "Informatika")
print(fanlar)        # ('Matematika', 'Fizika', 'Informatika')
print(len(fanlar))   # 3
Yaratish list’ga o‘xshaydi, faqat qavs boshqa: [ ] emas, ( ).

Vergulning sirli kuchi (1.69-rasm)

Tuple’ni qavs emas, vergul yaratadi. Bitta elementda vergul shart!

03

O‘zgarmaslik va metodlar

TypeError, list orqali o‘zgartirish, count() va index()

Tuple’ni o‘zgartirib bo‘lmaydi (1.71-rasm)


rang = (255, 128, 0)
rang[0] = 100
        
TypeError: 'tuple' object does not support item assignment
Tuple’da append(), remove() ham yo‘q - ular list metodlari.

O‘zgartirish kerak bo‘lsa: 3 qadam

1. Listga aylantiramiz

r = list(rang) -> [255, 128, 0]

2. O‘zgartiramiz

r[0] = 100 -> [100, 128, 0]

3. Yana tuple qilamiz

rang = tuple(r) -> (100, 128, 0)

count() va index() (1.72, 1.73-rasm)

Bashorat qiling

t = (10, 20, 30, 20) bo‘lsa, t.index(20) nimaga teng?

index() birinchi uchragan joyni qaytaradi: 20 avval 1-indeksda turibdi.

List yoki tuple?

list [ ]

O‘zgaruvchan. Metodlar ko‘p: append, insert, remove, pop, clear, sort... Fanlar ro‘yxati, xaridlar ro‘yxati.

tuple ( )

O‘zgarmas. Metodlar kam, ammo foydali: faqat count va index. Koordinata, rang, sozlama.
