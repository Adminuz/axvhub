02

Baholash tizimi

1.29-rasm: 86+, 71+, 56+ ballar taqsimoti

Baholar shkalasi taqsimoti

Baholash dasturi kodi

ball = 78

if ball >= 86:
    print("Baho: 5")
elif ball >= 71:
    print("Baho: 4")
elif ball >= 56:
    print("Baho: 3")
else:
    print("Baho: 2")
# Natija: Baho: 4
03

Rasmiy amaliy topshiriqlar

Qo‘llanmadagi 4 ta asosiy masalaning to‘liq yechimi

1-topshiriq: Sonning ishorasi

1 va 2-topshiriqlar kodi

1. Musbat / Manfiy / Nol

son = -5

if son > 0:
    print("Musbat son")
elif son < 0:
    print("Manfiy son")
else:
    print("Nolga teng")

2. Kattasini aniqlash

a, b = 25, 20

if a > b:
    print("Kattasi:", a)
elif b > a:
    print("Kattasi:", b)
else:
    print("Sonlar teng")

4-topshiriq: Harorat tavsiyasi

3 va 4-topshiriqlar kodi

3. Yosh toifasi

yosh = 15

if yosh <= 6:
    print("Bog‘cha yoshi")
elif yosh <= 17:
    print("Maktab o‘quvchisi")
else:
    print("Voyaga yetgan")

4. Harorat tavsiyasi

harorat = 25

if harorat < 0:
    print("Sovuq, qalin kiyining")
elif harorat <= 20:
    print("Salqin")
else:
    print("Issiq")

Sintaksisda uchraydigan 3 ta xato

Xato 1: = va ==

elif a < 0 ← Xato!

Xato 3: Chekinish

Amaliy topshiriq: 2-hafta loyihalari

Vaqt: 20 daqiqa · Darajalar bo‘yicha

1. Oson

Son musbat, manfiy yoki nol ekanligini aniqlovchi dastur yozing.

2. O'rta

Haroratga qarab ("Sovuq", "Salqin", "Issiq") tavsiya beruvchi dastur tuzing.

3. Qiyin

Uchta son ichidan eng kattasini if-elif-else orqali toping.

Tezkor sinov

Quyidagi kodda ball = 75 bo‘lsa nima chiqadi?

ball = 75
if ball >= 86:
    print("5")
elif ball >= 71:
    print("4")
else:
    print("Boshqa")
Javob: 4 (chunki 75 >= 71 → True)
