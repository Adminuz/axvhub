Chekinish (Indentation) qoidasi

Ball tekshiruvi kodi

Rasmiy qo'llanmadagi 1.27-rasm misoli

ball = 65

# Agar ball 60 dan katta yoki teng bo'lsa
if ball >= 60:
    print("O'tdi")
else:
    print("O'tmadi")
# Natija: O'tdi
ball = 45 bo'lsa, konsolda O'tmadi xabari chiqadi.
03

Qoldiq bilan if/else

Sonni juft yoki toqlikka tekshirish

Juft va toqlikni tekshirish algoritmi

Juft va toqlik dasturi kodi

son = 14

# Qoldiq 0 ga tengmi?
if son % 2 == 0:
    print("Juft")
else:
    print("Toq")
# Natija: Juft

Keys: Parol mosligi tekshiruvi

haqiqiy_parol = "admin2026"
kiritilgan_parol = "admin2026"

if kiritilgan_parol == haqiqiy_parol:
    print("Muvaffaqiyatli kirdingiz!")
    print("Boshqaruv paneli yuklanmoqda...")
else:
    print("Xato parol!")
    print("Qaytadan urinib ko'ring.")

Eng ko‘p uchraydigan 2 ta xato

Xato: Ikki nuqtani unutish

# Xato
if ball >= 60
    print("O'tdi")

# To'g'ri:
if ball >= 60:
    print("O'tdi")

Xato: IndentationError

# Xato (surilmadi)
if ball >= 60:
print("O'tdi")

# To'g'ri (4 space)
if ball >= 60:
    print("O'tdi")

Amaliy topshiriq: if/else sinovi

Vaqt: 15 daqiqa · Darajalar bo‘yicha

1. Oson

ball = 55. 60 dan kam bo'lsa "O'tmadi" deb chiqaruvchi shart yozing.

2. O'rta

Berilgan son juft yoki toqligini % 2 == 0 orqali aniqlang.

3. Qiyin

Xarid 100 000 so'mdan oshsa 10% chegirma hisoblab to'lovni chiqaring.

Tezkor sinov

Quyidagi kod ekranga nima chiqaradi?

yosh = 16
if yosh >= 18:
    print("Katta")
else:
    print("Kichik")
Javob: Kichik (chunki 16 >= 18 → False)
