Asosiy taqqoslash operatorlari

Taqqoslash operatorlari kodda

ball = 75
otish_bali = 60

# 1. Katta yoki tenglik tekshiruvi
natija = ball >= otish_bali
print("Imtihondan o'tdimi:", natija)  # True

# 2. Tenglik va teng emaslik
parol = "admin123"
print(parol == "admin123")  # True
print(parol != "12345")     # True
03

Mantiqiy operatorlar

and, or va not operatorlari

Mantiqiy operatorlar qoidasi

Mantiqiy ifodalar amalda

yosh = 15
tatildami = False

# Maktabga borish sharti
boradimi = (yosh >= 7 and yosh <= 18) and not tatildami
print("Maktabga boradi:", boradimi)  # True

# Chegirma sharti (yoki)
talabami = True
chegirma = (yosh < 18) or talabami
print("Chegirma beriladi:", chegirma)  # True

in va not in mexanizmi

Operatorlarda uchraydigan xatolar

Xato: = va == adashtirish

# XATO: qiymat berish amali
if ball = 60:
    print("O'tdi")

# TO'G'RI: taqqoslash amali
if ball == 60:
    print("O'tdi")

Xato: Matn va sonni taqqoslash

# Ehtiyot bo'ling!
print("10" > "2")
# Natija: False!
# Sababi: alifbo bo'yicha '1' < '2'
# To'g'risi: int("10") > int("2")

Amaliy topshiriq: Ifodalar va mantiq

Vaqt: 15 daqiqa · Darajalar bo‘yicha

1. Oson

ball = 85. Uning ball >= 60 shartini tekshirib konsolga chiqaring.

2. O'rta

yosh = 16 va ruxsatnoma = True. and orqali musobaqada qatnashish shartini tuzing.

3. Qiyin

Parol ichida "_" borligi va uzunligi 8 tadan kam emasligini bitta ifodada tekshiring.

Tezkor sinov

Quyidagi ifoda natijasi nima bo‘ladi?

x = 10
print(x > 5 and not (x == 10))
Javob: False (chunki not True → False, va True and False → False)
