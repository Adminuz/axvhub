02

Slicing

Stringdan kerakli bo‘lakni kesib olish

Slicing shakli (1.55-rasm)

word[1:4] qanday ishlaydi?

5 ta asosiy kesish

word[1:4] -> "yth"

1-indeksdan 4-gacha (4 kirmaydi)

word[:3] -> "Pyt"

Boshlanish yo‘q: 0 dan

word[3:] -> "hon"

Tugash yo‘q: oxirigacha

word[::2] -> "Pto"

Har ikkinchisi: 0, 2, 4

word[::-1] -> "nohtyP"

Teskari tartib

[::-1] bilan palindrom


soz = "radar"
if soz == soz[::-1]:
    print("Palindrom")
else:
    print("Palindrom emas")

radarkiyiknonallaqoshiq - emas
