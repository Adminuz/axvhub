Savol 1/10

Ma'lumotlar tuzilmasi nima?

Rasmiy ta'rif: saqlash ko'rinishi, tartibi va amallar usuli.

Savol 2/10

Noto'g'ri tuzilma tanlansa nima bo'ladi?

Hujjatda uchta oqibat ko'rsatilgan.

Savol 3/10

[1, 2, 3] qaysi tuzilma?

Kvadrat qavsdagi ketma-ket elementlar - list.

Savol 4/10

String nima?

String ichida harf, raqam, belgi va bo'sh joy bo'ladi.

Savol 5/10

type("Ali") natijasi?

Pythonda stringlar str turida.

Savol 6/10

Ko'p qatorli string qanday yoziladi?

Boshiga va oxiriga 3 tadan qo'shtirnoq.

Savol 7/10

s = "Python"; s[0] = "J" nima beradi?

String o'zgarmas (immutable).

Savol 8/10

"J" + "Python"[1:] natijasi?

[1:] - "ython", oldiga "J" qo'shildi.

Savol 9/10

Qaysi yozuv xato beradi?

Ichidagi apostrof stringni erta yopadi: tashqi qo'shtirnoq kerak.

Savol 10/10

s = "Salom"; t = s + "!". Keyin s nimaga teng?

+ yangi string yaratadi, asl s o'zgarmaydi.
