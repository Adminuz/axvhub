String o‘zgarmas

Immutable: o‘zgartirish o‘rniga yangi string

Stringni o‘zgartirib ko‘ramiz (1.52-rasm)


s = "Python"
s[0] = "J"
        
TypeError: 'str' object does not support item assignment

s[0] - 0-indeksdagi belgi (P). Python sanoqni 0 dan boshlaydi.

Yechim: yangi string yaratamiz (1.53-rasm)

Kodda isbot


s = "Python"
s2 = "J" + s[1:]
print(s)    # Python (o'zgarmadi)
print(s2)   # Jython

Immutable: 3 qadamda

1. String muhrlangan

Ichidagi belgini almashtirib bo‘lmaydi.

2. Kerakli qismni olamiz

s[1:] - asl stringdan nusxa bo‘lak.

3. Yangi string yasaymiz

"J" + s[1:] - + doim yangi string yaratadi.

Bashorat qiling

s = "Salom"; t = "K" + s[1:]; print(s, t) nima chiqaradi?

s o‘zgarmaydi; t - yangi string.

String bilan nima qila olamiz?

To‘g‘ridan-to‘g‘ri o‘zgartirish

s[0] = "J" -> TypeError

Yangi string yaratish

"J" + s[1:], s + "!" - asl string joyida qoladi.
