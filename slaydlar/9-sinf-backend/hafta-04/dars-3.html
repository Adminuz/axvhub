print(a[-1])     # e
print(a[1:4])    # ['b', 'c', 'd']

a = [1, 2]

remove() yoki pop()?

Qiymatni bilasiz

Lekin qayerdaligini bilmaysiz -> remove("Adabiyot")

Indeksni bilasiz

Va olingan qiymat kerak -> odam = navbat.pop(0)

Hammasini o‘chirish

clear() -> []

Metod - vazifa. Bosing

append(v)

bosing

oxiriga qo‘shadi

bosing

i-indeksga qo‘shadi

remove(v)

bosing

qiymat bo‘yicha birinchisini o‘chiradi

pop() / pop(i)

bosing

oxirgisini / i-indeksdagini olib tashlaydi

clear()

bosing

hammasini o‘chiradi

Bashorat qiling

a = [1, 2, 2, 3]; a.remove(2); x = a.pop(0); print(x, a)

remove(2) -> [1, 2, 3]; pop(0) 1 ni oladi -> [2, 3].
