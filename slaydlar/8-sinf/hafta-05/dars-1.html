O'qlar va tekislash

justify — asosiy o'q, align — ko'ndalang o'q

Ikki o'q

flex-direction

QiymatAsosiy o'q
row (standart)chapdan o'ngga →
row-reverseo'ngdan chapga ←
columnyuqoridan pastga ↓
column-reversepastdan yuqoriga ↑

justify-content

align-items va align-self

align-items

Hamma elementni ko'ndalang o'qda: stretch (standart), flex-start, center, flex-end, baseline.

align-self

Faqat bitta element: .maxsus { align-self: flex-end; }

Konteynerda balandlik bo'lmasa, vertikal tekislash ko'rinmaydi.

Markazlashning «oltin uchligi»


.markaz {
  display: flex;
  justify-content: center;  /* gorizontal */
  align-items: center;      /* vertikal */
  height: 300px;
}

Mini-test

flex-direction: column da justify-content: center qaysi yo'nalishda markazlaydi?

column da asosiy o'q yuqoridan pastga — justify shu o'q bo'yicha.

Ko'chirish va joyni bo'lish

flex-wrap, gap, flex-grow / shrink / basis

flex-wrap va gap

nowrap

Standart: sig'masa ham bitta qatorda siqiladi.
VS

wrap

Sig'magan element keyingi qatorga ko'chadi. gap: 16px — oralar.
