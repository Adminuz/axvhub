02

Media so'rovlar

@media, breakpoint, min va max

Sintaksis


body { background: lightyellow; }

Sintaksis


body { background: lightyellow; }
/* shart bajarilsa — pastdagi qoida ustun keladi */
@media (min-width: 768px) {
  body { background: lightblue; }
}

min-width yoki max-width?

(min-width: 768px)

bosing

Ekran kamida 768px — ya'ni 768 va undan keng.

(max-width: 767px)

bosing

Ekran ko'pi bilan 767px — ya'ni 767 va undan tor.

Oraliq: @media (min-width: 768px) and (max-width: 991px) — faqat planshet.

KenglikQurilma

Pastga bosing: qoida

Breakpointni qayerga qo'yish?

Qurilma nomiga emas — dizayn «buzilgan» kenglikka. Oynani asta toraytiring: qayerda noqulay bo'lsa, o'sha yerda breakpoint.

Bu raqamlar Bootstrap'da ham aynan shunday — keyingi mavzularda ko'rasiz.
