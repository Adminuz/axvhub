10 ta savol · taxminan 8 daqiqa

8-sinfWeb Full-stack4-hafta

Savol 1/10

CSS ning vazifasi nima?

HTML - tuzilma va mazmun, CSS - ko'rinish.

Savol 2/10

h1 { color: blue; } da color nima?

h1 - selektor, color - xususiyat, blue - qiymat.

Savol 3/10

Ko'p sahifaga bitta CSS faylini ulashning asosiy usuli?

External CSS <link> bilan ulanadi.

Savol 4/10

style.css fayli ichida nima yoziladi?

Tashqi faylda <style> yozilmaydi.

Savol 5/10

Class selektori qanday yoziladi?

Class - nuqta, id - panjara.

Savol 6/10

Sahifada faqat bir marta ishlatiladigan selektor?

Id yagona bo'ladi, class esa takrorlanadi.

Savol 7/10

nav a nimani tanlaydi?

Bu descendant (avlod) selektor.

Savol 8/10

h1, h2, h3 { color: navy; } qanday selektor?

Vergul bilan sanalgan selektorlar bitta qoidani oladi.

Savol 9/10

<p id="asosiy" class="xabar"> ga p - qizil, .xabar - yashil, #asosiy - ko'k. Matn rangi?

id (100) > class (10) > element (1).

Savol 10/10

karta { color: red; } nega class="karta" elementga ishlamaydi?

Class selektori .karta deb yoziladi.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: CSS qoidasi tuzilishi, 3 ta ulash usuli, 6 ta selektor, class va id, ustuvorlik.
