02

Padding va margin

Ichki va tashqi masofa

Padding yoki margin?

padding

Chegara ichidagi masofa
Fon rangi uni ham qoplaydi
VS

margin

Chegaradan tashqaridagi masofa
Shaffof: fon yo‘q

Qisqa yozuv: 1, 2 va 4 qiymat

Yozuvni o‘qing. Bosing

margin: 20px

bosing

to‘rt tomondan 20px

padding: 5px 15px

bosing

tepa-past 5px, chap-o‘ng 15px

margin-top: 30px

bosing

Mini-test

padding: 10px 20px 5px 0; - chap tomondagi ichki masofa qancha?

Soat mili bo‘yicha: tepa 10, o‘ng 20, past 5, chap 0.

04

O‘lcham va box-sizing

Quti aslida qancha joy egallaydi?

content-box: jami kenglik

box-sizing: ikki rejim

Odatiy holat

width = faqat content. Padding va border qo‘shiladi: 300px yozdik - 344px chiqdi.

* { box-sizing: border-box; }

width padding va borderni ham o‘z ichiga oladi: quti aniq 300px.

Hisoblaymiz: 3-topshiriq

width: 200px; padding: 10px; border: 5px solid; margin: 20px;

content-box: ko‘rinadigan

200 + 2·10 + 2·5 = 230px

content-box: margin bilan

230 + 2·20 = 270px

border-box

ko‘rinadigan 200px, margin bilan 240px

Blokni markazlash: margin: 0 auto


.konteyner {
  width: 600px;
  margin: 0 auto;   /* tepa-past 0, chap-o'ng teng */
}

width berilmasa, blok butun qatorni egallaydi va markazlanmaydi.

Bashorat qiling

* { box-sizing: border-box; } va .k { width: 250px; padding: 25px; border: 5px solid; }. Ko‘rinadigan kenglik?

border-box: padding va border width ichida. Quti aniq 250px.
