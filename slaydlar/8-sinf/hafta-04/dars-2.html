03

Meros olish

Inheritance: ota-elementdan bolaga

Meros daraxti

Nima o'tadi, nima o'tmaydi?

O'tadi

  • color
  • font-family, font-size
  • line-height, text-align

O'tmaydi

  • background-color
  • border
  • margin, padding

Meros amalda


body {
  color: #333;
  font-family: Arial, sans-serif;
}

.alohida {
  color: crimson;
}
    

<body>
  <h1>Sarlavha</h1>
  <p>Oddiy matn</p>
  <p class="alohida">Qizil</p>
</body>
