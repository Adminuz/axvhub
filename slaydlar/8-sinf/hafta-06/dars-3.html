.gitignore va push


echo ".env" >> .gitignore
echo "node_modules/" >> .gitignore
git add .gitignore
git commit -m ".gitignore qo'shildi"
git remote add origin https://github.com/username/maktab-sayti.git
git branch -M main
git push -u origin main
Parol, token va .env fayllarini hech qachon GitHub'ga yuklamang, ayniqsa Public repo'ga: ular butun dunyoga ko'rinadi. Tasodifan yuklangan bo'lsa, parolni darhol almashtiring.

«Maktab sayti» GitHub'da

  1. Loyiha papkasida git init qiling va birinchi commitni yarating.
  2. .gitignore qo'shing va yana ikkita mazmunli commit qiling.
  3. GitHub'da bo'sh repo yarating va push -u origin main bilan yuboring.
