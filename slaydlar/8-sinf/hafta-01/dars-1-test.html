8-sinfWeb Full-stack1-hafta

Savol 1/10

DNS (Domain Name System) nima vazifani bajaradi?

DNS «telefon kitobi» kabi: youtube.com ni kompyuter tushunadigan IP manzilga o'giradi.

Savol 2/10

Quyidagilardan qaysi biri IP manzil?

IP manzil — qurilmaning raqamlardan iborat manzili.

Savol 3/10

Server nima?

Server fayllarni saqlaydi va so'rov kelganda brauzerga jo'natadi.

Savol 4/10

Domen va hosting o'rtasidagi farq qaysi javobda to'g'ri?

Do'kon misoli: domen — manzil va nom, hosting — do'konning o'zi (bino).

Savol 5/10

HTTPS ning HTTP dan asosiy farqi nima?

HTTPS himoyalangan variant; manzil yonida qulf belgisi chiqadi.

Savol 6/10

Brauzer serverdan javob sifatida odatda nimani oladi?

Server sahifa fayllarini (HTML, CSS, JS, rasm) qaytaradi, brauzer ularni o'qib sahifani chizadi.

Savol 7/10

Sahifadagi tugma rangini qaysi qism belgilaydi?

Ko'rinadigan hamma narsa (rang, tugma, joylashuv) front-end vazifasi.

Savol 8/10

Foydalanuvchi kiritgan parolning to'g'riligini tekshirish kimning vazifasi?

Ma'lumotni saqlash, hisoblash va foydalanuvchini tekshirish serverda, ya'ni back-end da bajariladi.

Savol 9/10

Brauzerga https://mysite.uz yozildi. Birinchi qadam qaysi?

Avval IP topiladi, keyin shu IP dagi serverga so'rov ketadi, so'ng javob keladi va sahifa chiziladi.

Savol 10/10

www.mysite.uz manzilida uz qism nima deyiladi?

uz — yuqori daraja domeni, mysite — asosiy nom, www — subdomen.

Natijangiz

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.
