8-sinfWeb Full-stack1-hafta

Savol 1/20

Qurilmalar internetda bir-birini qanday topadi?

Har bir qurilmaning raqamli IP manzili bor, xuddi uyning ko'cha va uy raqami kabi.

Savol 2/20

Taqqoslash: internet — yo'llar tarmog'i bo'lsa, ma'lumot nimaga o'xshaydi?

Qurilmalar — uylar, ma'lumot — yo'llarda yuradigan mashinalar.

Savol 3/20

Klient (mijoz) deb nimaga aytiladi?

Klient so'rov yuboradi, server esa javob beradi.

Savol 4/20

Domen ro'yxatdan o'tkazilmasa nima bo'ladi?

Domen pulga olinadi, yillik to'lanadi va ro'yxatdan o'tgandan keyingina sizniki bo'ladi.

Savol 5/20

Parol yoki karta raqami kiritiladigan joyda nima bo'lishi shart?

HTTPS ma'lumotni shifrlaydi, shu sababli maxfiy ma'lumot faqat shunday sahifalarda kiritiladi.

Savol 6/20

Restoran misolida zal, menyu va ofitsiant nimaga mos keladi?

Zal — ko'rinadigan qism (front-end), oshxona va ombor — back-end.

Savol 7/20

HTML, CSS va JavaScript ni inson tanasiga solishtirsak, HTML nima?

HTML — tuzilma, CSS — ko'rinish, JavaScript — harakat.

Savol 8/20

<!DOCTYPE html> nimani bildiradi?

U teg emas, e'lon; hujjatning eng boshiga yoziladi.

Savol 9/20

Brauzer yorlig'ida (tab) qaysi teg ichidagi matn chiqadi?

<title> <head> ichida turadi va yorliqda ko'rinadi.

Savol 10/20

Telefonda sahifa to'g'ri masshtabda ko'rinishi uchun qaysi teg kerak?

viewport meta tegi qurilma kengligiga moslashni ta'minlaydi.

Savol 11/20

Qaysi ketma-ketlik sarlavhalar tartibiga mos?

Tartibni buzmaslik kerak; sarlavha mazmun darajasini bildiradi.

Savol 12/20

<abbr title="Domain Name System">DNS</abbr> da title nima qiladi?

abbr qisqartmani belgilaydi, title esa to'liq izohni beradi.

Savol 13/20

O'z saytingizdagi sahifaga havola uchun qaysi yo'l mos (nisbiy yo'l)?

Boshqa sayt uchun to'liq manzil, o'z saytingiz uchun nisbiy yo'l yoziladi.

Savol 14/20

download atributi havolada nima qiladi?

download bosilganda fayl ochilmay, yuklab olinadi.

Savol 15/20

Nega <u> ni kamdan-kam ishlatish tavsiya etiladi?

<u> ma'no bermaydi va foydalanuvchi uni havola deb o'ylashi mumkin.

Savol 16/20

Ma'nosiz konteyner sifatida, keyinchalik CSS bilan bezash uchun qaysi teg ishlatiladi?

<span> ma'no bermaydi, faqat qator ichidagi qismni ajratadi.

Savol 17/20

Foydalanuvchi sahifadagi tugmani bosganda parol tekshiriladi. Bu jarayon qaysi qismlar ishtirokida bo'ladi?

Tugma brauzerda ko'rinadi (front-end), tekshirish serverda (back-end) bajariladi.

Savol 18/20

Server brauzerga HTML fayl yubordi. Brauzer undagi <h1> va <p> ni qanday tushunadi?

Brauzer HTML faylni o'qib, teglarga qarab sahifani chizadi.

Savol 19/20

Do'stingiz mysite.uz saytiga havola berdi. Havolani bosganingizda eng avval nima ishga tushadi?

Havola ham oddiy manzil kabi: avval DNS orqali IP topiladi.

Savol 20/20

Sayt yasayotgan o'quvchi salom.html faylini saqlab brauzerda ochdi. Bu fayl qaysi qismga kiradi?

HTML fayl brauzer ko'rsatadigan tuzilmani beradi, ya'ni front-end.
