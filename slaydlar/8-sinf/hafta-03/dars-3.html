Maxsus va Global atributlar farqi

id va class: Qaysi birini qachon ishlatamiz?

id (Yagona identifikator)

  • Sahifada faqat bitta elementga beriladi
  • Takrorlanmas yagona nom (Pasport kabi)
  • CSS da #nomi bilan, JavaScript da oson topiladi
Misol: id="asosiy-menyusi"

class (Sinf nomi)

  • Bir nechta elementlarga bir xil berilishi mumkin
  • Umumiy guruh yoki dizayn shabloni
  • Bitta elementda bir nechta class bo'lishi mumkin
Misol: class="card highlighted"

data-* orqali yashirin ma'lumot saqlash

Sehrli atributlar: contenteditable va hidden

contenteditable="true"

Elementni brauzerda Word kabi to'g'ridan-to'g'ri tahrirlanadigan qiladi. Matnni o'chirish, qo'shish mumkin.

Google Docs yoki Notion kabi dasturlar asosida turadi

hidden

Mantiqiy atribut. Agar elementga yozilsa, u sahifada ko'rinmay turadi. JavaScript orqali ochib-yopish uchun qulay.

Vaqtinchalik xabarlarni berkitishda ishlatiladi
