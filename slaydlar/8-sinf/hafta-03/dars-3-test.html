8-sinfWeb Full-stack3-hafta

Savol 1/10

Global atribut nima?

href faqat <a> da, id esa barcha teglarda ishlaydi.

Savol 2/10

Bir sahifada id qiymati qanday bo'lishi kerak?

id bitta elementni aniqlaydi, shuning uchun sahifada faqat bir marta uchraydi.

Savol 3/10

Bir nechta elementni umumiy guruhga birlashtirish uchun qaysi atribut?

Bitta elementda bir nechta class bo'sh joy bilan yozilishi mumkin.

Savol 4/10

hidden atributli element nima bo'ladi?

hidden CSS dagi display: none ga teng.

Savol 5/10

Foydalanuvchi sarlavhani Word kabi to'g'ridan-to'g'ri brauzerda o'zgartira olishi uchun qaysi atribut?

contenteditable elementni tahrirlanadigan qiladi.

Savol 6/10

tabindex nimani belgilaydi?

tabindex="1", "2" klaviatura bilan o'tish ketma-ketligini beradi.

Savol 7/10

data-* atributlari nima uchun kerak?

Masalan data-id="101", yulduzcha o'rniga istalgan so'z yoziladi.

Savol 8/10

Rang tanlash palitrasini ochuvchi input turi qaysi?

color palitrani, range slayderni ochadi.

Savol 9/10

O'ngga-chapga suriladigan slayder yaratish uchun qaysi tur?

range qiymatni sudrab o'zgartirishga imkon beradi.

Savol 10/10

Quyidagi kodda qanday muammo bor? <p id="a">1</p><p id="a">2</p>

id bitta sahifada faqat 1 marta kelishi shart; umumiy guruh uchun class ishlatiladi.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: global atributlar (id, class, title, data-*, hidden, contenteditable, tabindex) va yangi input turlari.
