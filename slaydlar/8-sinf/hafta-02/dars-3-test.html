8-sinfWeb Full-stack2-hafta

Savol 1/10

<form> ning action atributi nimani belgilaydi?

action — server manzili yoki fayl; usulni method beradi.

Savol 2/10

Parol va to'lov ma'lumotlarini yuborishda qaysi method ishlatiladi?

GET ma'lumotni URL da ochiq ko'rsatadi, POST esa so'rov tanasida yuboradi.

Savol 3/10

<label for="ism"> qaysi input bilan bog'lanadi?

for qiymati input ning id siga teng bo'lishi shart.

Savol 4/10

Yashirin yulduzcha (••••) bilan ko'rinadigan maydon turi qaysi?

password kiritilgan belgilarni yashiradi.

Savol 5/10

Berilgan variantlardan faqat bittasini tanlash uchun qaysi input turi ishlatiladi?

checkbox da bir nechta bandni tanlash mumkin, radio da faqat bittasi.

Savol 6/10

Radio tugmalar bitta guruhga kirishi uchun nima bir xil bo'lishi shart?

Bir xil name tugmalarni guruhlaydi, shuning uchun bittasi tanlansa boshqasi o'chadi.

Savol 7/10

Maydonni to'ldirish majburiy bo'lishi uchun qaysi atribut yoziladi?

required — bo'sh qoldirib yuborib bo'lmaydi.

Savol 8/10

Ochiluvchi ro'yxat (dropdown) qaysi teglar bilan yasaladi?

<select> ichida har bir variant <option> bilan beriladi.

Savol 9/10

Foydalanuvchi maydonga yozuv kirita olmaydi, qiymati serverga ham yuborilmaydi. Qaysi atribut qo'yilgan?

disabled maydonni butunlay nofaol qiladi va yubormaydi; readonly o'zgartirib bo'lmaydi, lekin ko'rinadi.

Savol 10/10

Forma yuborildi, lekin server name bo'sh bo'lgan maydon qiymatini ko'rmayapti. Sababi nima?

name — ma'lumot serverga qaysi nom bilan borishini belgilaydi.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: form, label va id, input turlari, radio va name, validatsiya atributlari.
