8-sinfWeb Full-stack2-hafta

Savol 1/10

Rasm faylining manzili <img> ning qaysi atributida yoziladi?

src (source) — majburiy atribut, rasm manzilini beradi.

Savol 2/10

alt atributi nima uchun kerak?

alt — alternativ matn; SEO uchun ham muhim, uni bo'sh qoldirmang.

Savol 3/10

<img> qanday teg?

<img> ga </img> yozilmaydi; u qator ichida joylashadi.

Savol 4/10

Rasm tagiga izoh qo'shish uchun qaysi teglar juftligi ishlatiladi?

<figure> rasm va izohni bitta semantik blokka birlashtiradi.

Savol 5/10

Nisbiy yo'l images/foto.jpg nimani bildiradi?

Nisbiy yo'l HTML fayl turgan joyga nisbatan hisoblanadi.

Savol 6/10

Tartibi muhim bo'lgan ro'yxat (taom tayyorlash bosqichlari) uchun qaysi teg?

<ol> raqamlangan ro'yxat, <ul> tartibsiz.

Savol 7/10

<dl> ro'yxatida atama qaysi tegda, izohi qaysi tegda yoziladi?

dt — description term, dd — description details.

Savol 8/10

<ol start="5"> da birinchi band qaysi raqam bilan boshlanadi?

start atributi raqamlashni berilgan sondan boshlaydi.

Savol 9/10

Ichma-ich ro'yxatda ichki <ul> qayerga yoziladi?

Ichki ro'yxat doimo ota <li> ichida ochilib, shu yerda yopiladi.

Savol 10/10

Rasm images papkasida, HTML fayl esa pages papkasida. Ikkalasi bitta umumiy papka ichida. pages/sahifa.html dan rasmga to'g'ri yo'l qaysi?

../ bir pog'ona yuqoriga chiqaradi, so'ng images papkasiga kiriladi.
