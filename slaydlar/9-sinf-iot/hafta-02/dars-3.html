Arduino Uno R3 Asosiy Ko'rsatkichlari

ATmega328P Chip

8-bitli AVR protsessor, 16 MGts takt chastotasi.

Sekundiga 16 million buyruq bajarish quvvatiga ega.

Xotira Hajmi

32 KB Flash dastur xotirasi;

2 KB SRAM (tezkor o'zgaruvchilar);

1 KB EEPROM doimiy xotirasi.

Quvvat Ta'minoti

USB kabeli (5V) yoki DC raz'yomi (7–12V).

Platada 5V, 3.3V va 3 ta GND pinlari mavjud.

Arduino Uno Pinlar Anatomiyasi

GPIO Pinlar Nima?

INPUT (Kirish Rejimi)

Tashqi sensorlar va tugmalardan signallarni o'qiydi.

Tugma bosildimi? Harorat oshdimi? Xonada harakat bormi?

Pin o'zidan tok chiqarmaydi, faqat kuchlanishni tekshiradi.

OUTPUT (Chiqish Rejimi)

Ijrochi organlar (LED, rele, motor, buzzer)ga elektr toki yuboradi.

HIGH (1): 5V kuchlanish uzatiladi (LED yonadi);

LOW (0): 0V kuchlanish (LED o'chadi).

Sxemani Yig'ish va C++ Kodi

Arduino 9-piniga LED ulash va Blink dasturi

Elektron Sxemaning Bog'lanish Sxemasi

Arduino C++ Dastur Arxitekturasi

void setup() { ... }

Mikrokontroller yoqilganda faqat 1 marta ishga tushadi.

Dastlabki sozlamalar: qaysi pin kirish va qaysi pin chiqish ekanligi belgilanadi.

Masalan: pinMode(9, OUTPUT);

void loop() { ... }

setup() tugagach, doimiy va cheksiz takrorlanuvchi tsikl.

Asosiy algoritm mantiqi: yoqish, kutish, o'chirish, yana kutish shu yerda aylanadi.

Quvvat uzilguncha to'xtovsiz ishlaydi.

To'liq C++ Dastur Kodi (Blink)

int LED = 9; // LED ulangan raqamli pin

void setup() {
  pinMode(LED, OUTPUT); // 9-pinni chiqish qilib sozlaymiz
}

void loop() {
  digitalWrite(LED, 1); // LEDni yoqish (5V signal)
  delay(2000);          // 2000 millisekund (2 soniya) kutish
  digitalWrite(LED, 0); // LEDni o'chirish (0V signal)
  delay(1000);          // 1000 millisekund (1 soniya) kutish
}

Asosiy Funksiyalar Izohi

pinMode(pin, rejim)

Pinni OUTPUT (chiqish) yoki INPUT (kirish) qilib dasturiy sozlaydi.

digitalWrite(pin, holat)

Pinga HIGH (1 — 5V) yoki LOW (0 — 0V) mantiqiy signal uzatadi.

delay(vaqt_ms)

Mikrokontroller ishini ko'rsatilgan millisekund davomida to'xtatib turadi (1000 ms = 1 s).

Interaktiv Kartochkalar

void loop() funksiyasi necha marta bajariladi?

Javobni ko'rish uchun aylantiring

Cheksiz Takrorlanadi

setup() 1 marta bajarilgach, loop() mikrokontroller quvvati uzilmaguncha to'xtovsiz aylanadi.

delay(2500) kodi necha soniya kutadi?

Javobni ko'rish uchun aylantiring

2.5 Soniya

1000 ms = 1 soniya bo'lgani uchun, 2500 ms = 2.5 soniya tanaffus beradi.
