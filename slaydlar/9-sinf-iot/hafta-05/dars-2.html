Amaliyot

Arduino IDE va Wi-Fi'ga ulanish

Arduino IDE'ga ESP qo'shish

1. Preferences

File → Preferences → Additional boards manager URLs — Espressif URL.

2. Boards Manager

Tools → Board → Boards Manager — «esp32» / «esp8266» o'rnatish.

3. Plata

Tools → Board — «ESP32 Dev Module» yoki «NodeMCU 1.0».

4. Port

Tools → Port; Serial Monitor tezligi — 115200.

Wi-Fi'ga ulanish


#include <WiFi.h>   // ESP8266 da: ESP8266WiFi.h
const char* ssid  = "Maktab_WiFi";
const char* parol = "********";
void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, parol);          // Station rejimi
  // ulanguncha kutamiz
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println(WiFi.localIP());   // DHCP bergan IP
  Serial.println(WiFi.RSSI());      // signal kuchi, dBm
}
void loop() { }

Natijani o'qish

IP-manzil

192.168.1.37 — router DHCP orqali bergan lokal manzil.

RSSI

-78 dBm — −70 dan past: aloqa beqaror, routerga yaqinlashtiring.

Parolni kodda ochiq qoldirib GitHub'ga yuklamang. 5 GHz tarmoqqa ESP ulanmaydi — 2.4 GHz kerak.
