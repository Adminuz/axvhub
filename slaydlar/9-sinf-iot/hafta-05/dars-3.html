Tugma → LED


const int TUGMA = 2;
const int LED = 13;
int holat = 0;          // RAM
void setup() {
  pinMode(TUGMA, INPUT);   // «quloq»
  pinMode(LED, OUTPUT);    // «qo'l»
}
void loop() {
  holat = digitalRead(TUGMA);   // port xabar oladi
  if (holat == HIGH) {          // CPU qaror qiladi
    digitalWrite(LED, HIGH);    // port javob beradi
  } else {
    digitalWrite(LED, LOW);
  }
}

Ehtiyot bo'ling

pinMode() yozilmasa pin kutilgandek ishlamaydi. Tugmaga pull-down rezistor (10 kΩ) yoki INPUT_PULLUP kerak — aks holda qiymat «suzib yuradi».
«Mikrokontrollerda ham Windows bor» — yo'q: odatda OS yo'q, bitta dastur loop() da aylanadi.
