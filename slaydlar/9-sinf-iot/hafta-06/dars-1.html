ADC qiymati va kuchlanish


Arduino Uno: 10-bit ADC, 5 V

qiymat    kuchlanish (U = 5 * qiymat / 1023)
   0      0.00 V
 256      1.25 V
 512      2.50 V
 768      3.75 V
1023      5.00 V
Formulani yodlash shart emas: «5 V ni 1023 ga bo'ldik» — har birlik ≈ 0,0049 V (taxminan 4,9 mV).

Chegara dasturi


const int SENSOR = A0;     // analog kirish
const int LED = 9;         // chiqish (PWM pin)
const int CHEGARA = 512;   // ~2,5 V

void setup() {
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int qiymat = analogRead(SENSOR);   // 0..1023
  Serial.println(qiymat);
  if (qiymat > CHEGARA) {
    analogWrite(LED, 255);           // to'liq yorqin
  } else {
    analogWrite(LED, 40);            // xira
  }
  delay(200);
}
Chegarani o'zgartirib ko'ring: 300, 700. Serial Monitor'da qiymat o'zgarishini kuzating — shunda sensor «tilini» tushunasiz.

Mini-test

analogWrite(LED, 128) LEDni qanday yoqadi?

128/255 ≈ 50%.
