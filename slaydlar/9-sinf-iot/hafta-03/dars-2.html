OUTPUT vs INPUT Signallari

OUTPUT (Chiqish)

Arduino tashqi qurilmalarga signal yuboradi: LEDni yoqish, tovush chiqarish, motor aylantirish.

Biz mikrokontrollerga buyruq beramiz, u ijro etadi.

INPUT (Kirish)

Arduino tashqi sensorlar va tugmalardan ma'lumot qabul qiladi.

Tugma bosildimi? Eshik ochildimi? Xona qorong'imi?

Mikrokontroller atrof-muhitni "his qiladi".

Suzuvchi Pin va INPUT_PULLUP

Tasodifiy elektromagnit to'lqinlardan himoyalanish siri

"Suzuvchi Pin" (Floating Pin) Muammosi

Havoda Osilib Qolgan Pin

Agar tugma qo'yib yuborilganda pin hech qayerga ulanmay qolsa:

Pin mikroantennaga aylanadi va atrofdagi simlar, tarmoq to'lqinlarini ushlaydi.

Natijada goh 0, goh 1 o'qib, o'z-o'zidan LEDni yoqib-o'chirib yuboradi!

Bartaraf Etish: Aniq Potensialga Tortish

Pinni har doim yo 5V ga (Pull-up) yoki GND ga (Pull-down) rezistor orqali bog'lab qo'yish kerak.

Shunda tugma bo'sh turganda ham pin aniq bir mantiqiy darajani bilib turadi.

INPUT_PULLUP: Ichki Tortuvchi Rezistor

03

Serial Monitor bilan Ishlash

Arduino va kompyuter o'rtasida ma'lumot almashish

Serial Monitor Ma'lumotlar Oqimi

Tugmani O'qish C++ Kodi

const int buttonPin = 2; // Tugma ulangan pin

void setup() {
  pinMode(buttonPin, INPUT_PULLUP); // Ichki rezistor bilan kirish
  Serial.begin(9600);               // 9600 tezlikda aloqa o'rnatish
}

void loop() {
  int buttonState = digitalRead(buttonPin); // Pin holatini o'qish
  Serial.print("Tugma holati: ");
  Serial.println(buttonState);              // Ekranga chop etish
  delay(200);                               // 200 ms kutish
}

Tugma Bilan LEDni Boshqarish Kodi

const int buttonPin = 2;
const int ledPin = 9;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(buttonPin);

  if (buttonState == LOW) {     // Agar tugma bosilsa (0)
    digitalWrite(ledPin, HIGH); // LED yonadi
  } else {                      // Agar tugma qo'yib yuborilsa (1)
    digitalWrite(ledPin, LOW);  // LED o'chadi
  }
}
