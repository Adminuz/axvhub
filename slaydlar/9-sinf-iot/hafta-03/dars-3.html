Toggle (Trigged) Mantig'i

Tugmani bir marta bosganda holatni doimiy saqlab qolish siri

Bosib Turish (Hold) vs Bosib Qo'yib Yuborish (Toggle)

Hold (Bosib Turish)

LED faqat tugma barmog'ingiz ostida ushlab turilgandagina yonadi.

Qo'l olinsa zudlik bilan o'chadi (qo'ng'iroq, siren).

Toggle (Holatni Almashtirish)

1 marta bosildi: LED yondi va yoniq qoladi.

Yana 1 marta bosildi: LED o'chdi va o'chiq qoladi.

Xona chirog'i, televizor, kompyuter yoqish tugmasi.

03

Holat O'zgarishini Aniqlash

State Change Detection va Toggle C++ algoritmi

O'tish Lahzasini Usulash (Edge Detection)

Oldingi Holatni Saqlash

Dasturda lastButtonState o'zgaruvchisi kiritiladi.

Har siklda joriy holat avvalgisi bilan solishtiriladi:

reading != lastButtonState

Bosilish Lahzasi (LOW)

Agar holat o'zgargan bo'lsa VA yangi holat LOW bo'lsa:

ledState = !ledState;

LED holati darhol teskarisiga aylanadi (0 -> 1, 1 -> 0).

To'liq Toggle C++ Kodi

const int btnPin = 2;
const int ledPin = 9;

int ledState = LOW;
int lastBtn = HIGH;

void setup() {
  pinMode(btnPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int reading = digitalRead(btnPin);

  // Agar tugma yangi bosilgan bo'lsa:
  if (reading != lastBtn && reading == LOW) {
    ledState = !ledState;           // Invert (Toggle)
    digitalWrite(ledPin, ledState); // Yangi holatni uzatish
    delay(50);                      // Debounce filtri
  }
  lastBtn = reading;                // Holatni yangilash
}
