Ketma-ket Ulanish (Series Circuit)

Ketma-ket Ulanishning Kamchiliklari

Kuchlanish Yetishmovchiligi

Ikkita LED ulanganda $2\text{V} + 2\text{V} = 4\text{V}$ sarflanadi.

Agar 3 ta LED ulansa ($6\text{V} > 5\text{V}$), Arduino ning 5V kuchlanishi yetmay qoladi va chiroqlar umuman yonmaydi!

Biri O'chsa — Hammasi O'chadi

Ketma-ket zanjirdagi bitta detal kuyib uzilsa, elektr toki oqimi butunlay to'xtaydi.

Eski yangi yil archa chiroqlaridagi muammo aynan shunday edi.

Arduino Orqali Boshqaruv

Pin 9 va Pin 11 yordamida ikkita chiroqni dasturlash

Nega Alohida Pinlar Kerak?

Mustaqil Algoritm

Agar ikkala LED bitta pinga ulansa, ular faqat bir vaqtda yonadi va o'chadi.

Alohida pinlar (Pin 9 va 11) har bir chiroqni xohlagan tartibda yoqish imkonini beradi.

Alohida Rezistor Zarurati

Har bir LED uchun alohida 220 Om rezistor qo'yilishi shart.

Aks holda, biri yonganda va ikkalasi yonganda tok o'zgarib, chiroqlar bir tekis nur sochmaydi.

Dastur Kodi va Mantiq

Navbatma-navbat yoqish algoritmi tahlili

Rasmiy C++ Dastur Kodi

int red = 9;     // Qizil LED Arduino 9-pinga ulangan
int yellow = 11; // Sariq LED Arduino 11-pinga ulangan

void setup() {
  pinMode(red, OUTPUT);    // 9-pin chiqish sifatida
  pinMode(yellow, OUTPUT); // 11-pin chiqish sifatida
}

void loop() {
  digitalWrite(red, 1);    // Qizil LED yoqiladi
  delay(5000);             // 5 soniya kutadi
  digitalWrite(red, 0);    // Qizil LED o'chiriladi
  digitalWrite(yellow, 1); // Sariq LED yoqiladi
  delay(2000);             // 2 soniya kutadi
  digitalWrite(yellow, 0); // Sariq LED o'chiriladi
  delay(5000);             // Ikkalasi ham o'chiq 5 soniya kutadi
}
