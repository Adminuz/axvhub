Yordamchi funksiya


bool checkSwitch(byte pin, byte &lastState) {
  byte current = digitalRead(pin);
  if (current != lastState) {     // holat o'zgardimi?
    lastState = current;          // eslab qolamiz
    if (current == Pressed) return true;
  }
  return false;
}

Funksiya true ni faqat bosilgan lahzada qaytaradi.

millis() andozasi


unsigned long oxirgiVaqt = 0;
const unsigned long INTERVAL = 700;

void loop() {
  if (millis() - oxirgiVaqt >= INTERVAL) {
    oxirgiVaqt = millis();
    digitalWrite(13, !digitalRead(13));   // heartbeat
  }
  // boshqa ishlar to'xtovsiz
}
Vaqt o'zgaruvchisi faqat unsigned long: int 33 soniyada to'lib ketadi.

03

Rejimlar

Bitta tugma — 4 ta holat

Holat mashinasi

0 · O'CHIQ

LED doim o'chiq.

1 · YONIQ

LED doim yoniq.

2 · SEKIN

500 ms da almashadi.

3 · TEZ

100 ms da almashadi, so'ng yana 0.

mode = (mode + 1) % 4; — 3 dan keyin qoldiq 0.

switch / case


switch (mode) {
  case 0: digitalWrite(LED, LOW);  break;
  case 1: digitalWrite(LED, HIGH); break;
  case 2: miltilla(500);           break;
  case 3: miltilla(100);           break;
}
miltilla() ichida ham millis() — tugma miltillash paytida ham seziladi.
