Savol 1/10

Git qanday tizim?

Git fayl va satr darajasidagi o'zgarishlarni vaqt bo'yicha qayd etadi.

Savol 2/10

Gitning «tarqoqlik» xususiyati nimani bildiradi?

Shu sabab Git markazlashgan tizimlardan farq qiladi.

Savol 3/10

Git o'rnatilgach, birinchi navbatda nima sozlanadi?

Ular har commit ostida muallifni ko'rsatadi: git config --global user.name "...".

Savol 4/10

Fayllar Gitda qaysi 3 maydondan o'tadi?

Ishchi maydon, tayyorlash maydoni va .git ombori.

Savol 5/10

git init nima hosil qiladi?

Loyihaning butun tarixi shu papkada saqlanadi, uni o'chirmaslik kerak.

Savol 6/10

git add va git commit farqi nimada?

Avval Staging Area ga olinadi, so'ng commit qilinadi.

Savol 7/10

git status da qizil rangdagi fayllar nimani bildiradi?

Yashil rang esa staged, ya'ni commitga tayyor fayllar.

Savol 8/10

Commitlar tarixini qisqa va grafik ko'rinishda qaysi buyruq chiqaradi?

git log tarixni, --oneline esa qisqa ko'rinishni beradi.

Savol 9/10

local.properties ni nega Gitga qo'shmaslik kerak?

Boshqa kompyuterda SDK yo'li boshqacha, kalitlar esa sizib chiqishi mumkin.

Savol 10/10

.gitignore yo'q va build/ papkasi ham commit qilindi. Oqibati qaysi?

build/, .gradle/, *.apk, *.aab kabilar .gitignore ga yoziladi.
