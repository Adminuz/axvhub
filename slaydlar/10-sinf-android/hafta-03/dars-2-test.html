10-sinfAdvanced Android3-hafta

Savol 1/10

Nega yangi funksiyani main da emas, alohida branch'da yoziladi?

Branch asosiy loyihadan ajralgan «parallel olam».

Savol 2/10

Yangi branch yaratib unga o'tadigan zamonaviy buyruq qaysi?

Eski usuli: git checkout -b feature-bonus.

Savol 3/10

Ishlatib bo'lingan branch'ni o'chirish buyrug'i?

-d branch'ni xavfsiz o'chiradi.

Savol 4/10

git diff da yashil + va qizil - nimani bildiradi?

Commitdan oldin aynan nima o'zgarganini ko'rsatadi.

Savol 5/10

feature-bonus ni main ga qo'shish uchun qanday ishlanadi?

Birlashtirish qabul qiluvchi branch ustida turib bajariladi.

Savol 6/10

Merge Conflict qachon yuz beradi?

Git qaysi variant to'g'ri ekanini o'zi hal qila olmaydi.

Savol 7/10

Konflikt belgilarida <<<<<<< HEAD dan ======= gacha qismda nima bor?

======= dan >>>>>>> feature-bonus gacha esa qo'shilayotgan branch kodi.

Savol 8/10

Konfliktni hal qilishning to'g'ri tartibi qaysi?

Ajratuvchi belgilar fayldan butunlay olib tashlanishi shart.

Savol 9/10

Chala kodni commit qilmay main dagi xatoni tuzatish uchun nima qilinadi?

Stash o'zgarishlarni vaqtincha «xaltaga» solib turadi.

Savol 10/10

git revert <hash> nima qiladi?

Allaqachon commit qilingan o'zgarishni xavfsiz bekor qilish usuli.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: Branch, switch, diff, merge va conflict, stash, revert.
