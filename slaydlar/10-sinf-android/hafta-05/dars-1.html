android{} bloki qismlari

app/build.gradle.kts


plugins {
    id("com.android.application")
    id("org.jetbrains.kotlin.android")
}

android {
    namespace = "com.example.advanced"
    compileSdk = 34

    defaultConfig {
        applicationId = "com.example.advanced"
        minSdk = 24
        targetSdk = 34
        versionCode = 1
        versionName = "1.0"

minSdk ni noto'g'ri tanlash ilovaning eski telefonlarda ishlamasligiga olib keladi. Har nashrda versionCode oshirilishi shart.

03

Modullar bog'lanishi

include va project(...)

Modul bog'lanish yo'li

Modul qo'shish


// settings.gradle.kts
include(":app")
include(":core")

// core/build.gradle.kts
plugins {
    id("com.android.library")
    id("org.jetbrains.kotlin.android")
}

// app/build.gradle.kts
dependencies {
    implementation(project(":core"))
}
Fayllarni o'zgartirgach Android Studio dagi Sync Now tugmasini bosing. app -> core yo'nalishi to'g'ri, teskarisi (core -> app) tsikl hosil qiladi.

Mini-test

app modulidan core modulini ishlatish uchun nima yoziladi?

Modul avval settings da e'lon qilinadi, so'ng project(...) bilan ulanadi.

Project-level va module-level

Project-level

Butun loyiha uchun umumiy plaginlar va sozlamalar
VS

Module-level

Aynan shu modul: android {}, defaultConfig, dependencies {}

Ilovaning asosiy sozlamalari module-level faylda.

Asosiy parametrlar. Bosing

applicationId

bosing

Ilovaning noyob nomi: com.example.advanced

minSdk / targetSdk

bosing

Eng past va moslashtirilgan Android versiyasi

versionCode

bosing

Ichki butun versiya raqami: har nashrda oshadi

versionName

bosing

Foydalanuvchiga ko'rinadigan versiya: 1.0

Yangi modul qo'shish

1. Modul yarating

File > New > New Module > Android Library.

2. include qiling

settings.gradle.kts da include(":core").

3. Ulang

app da implementation(project(":core")) va Sync.

Amaliy topshiriq 20 daqiqa

OsonAtamalar: settings.gradle, project-level va module-level build.gradle vazifasini bir jumlada yozing.
O'rtadefaultConfig o'qish: Berilgan defaultConfig ni o'qing va minSdk, versionName qiymatlarini ayting.
O'rtaModul qo'shish: core kutubxona modulini yarating va app ga ulang.
QiyinXatoni toping: app moduli core ni ishlatmoqda, lekin Unresolved reference xatosi chiqdi. 2 ta mumkin bo'lgan sababni yozing.
QiyinversionCode siyosati: Ilovaning 1.0 (kod 1), 1.1 va 2.0 versiyalari uchun versionCode va versionName ni yozing.
