01

implementation va api

Kim ko'radi?

Ko'rinish

core moduli


// core/build.gradle.kts
dependencies {
    implementation("com.google.code.gson:gson:2.10.1")   // faqat core ichida
    api("com.squareup.retrofit2:retrofit:2.9.0")         // app ham ko'radi
}

// app/build.gradle.kts
dependencies {
    implementation(project(":core"))
}
Shubhalansangiz, implementation yozing. api keraksiz yozilsa, modullar orasida ortiqcha bog'liqlik va sekin build paydo bo'ladi.

Pastga bosing: tekshirish

Turlarni tekshirish

  1. core moduliga kutubxonani implementation bilan ulang.
  2. app dan uning sinfini ishlatib ko'ring: xato chiqadi.
  3. Turni api ga o'zgartiring va xato yo'qolganini ko'ring.

OsonTurni tanlang: JUnit, Coil, annotatsiya va drayver uchun tur tanlang.
Osonimplementation yoki api: core dagi Gson faqat core ichida ishlatiladi. Qaysi tur to'g'ri?
O'rtaRetrofit ni oching: core Retrofit ni app ga ochishi kerak. Yozing.
O'rtaTest kutubxonalari: JUnit va Espresso ni to'g'ri turlar bilan yozing.
QiyinIkki modul: core da Retrofit (api), Gson (implementation); app core ga bog'lansin.
QiyinXatoni tushuntiring: app Gson ni ishlatdi, core da u implementation. Nima bo'ladi, qanday tuzatasiz?
