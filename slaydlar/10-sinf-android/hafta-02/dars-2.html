02

R8 Optimallashtirishning 4 Bosqichi

Shrinking, Resource Shrinking, Optimization va Obfuscation

4 ta fundamental operatsiya

1. Code Shrinking (Tree Shaking)

Loyihadagi foydalanilmagan sinflar, metodlar va o'zgaruvchilarni ildizidan tozalaydi.

2. Resource Shrinking

Koddagi keraksiz qismlar o'chirilgach, ishlatilmay qolgan rasmlar va XML fayllarni ham chiqarib tashlaydi.

3. Optimization

Kodni tahlil qilib, bo'sh if-else larni olib tashlaydi, funksiyalarni inline qiladi.

4. Obfuscation

Klass, metod va maydon nomlarini qisqa tushunarsiz harflarga (a, b, c) aylantiradi.

Tree Shaking: Keraksiz kodlarni tozalash

Obfuscation: Kod nomlarini chalkashtirish

03

build.gradle Sozlamalari

minifyEnabled, shrinkResources va standart qoidalar

Release rejimida R8 ni yoqish

Konfiguratsiya kodi

buildTypes {
    release {
        minifyEnabled true
        shrinkResources true
        proguardFiles(
            getDefaultProguardFile(
                "proguard-android-optimize.txt"
            ),
            "proguard-rules.pro"
        )
    }
}

Muhim qoidalar

shrinkResources true — faqat minifyEnabled true bilan ishlaydi.

proguard-android-optimize.txt — Google tomonidan taqdim etilgan universal optimallashtirish qoidalari.

proguard-rules.pro — Sizning loyihangizga xos maxsus qoidalar fayli.

Optimallashtirilmagan vs R8 bilan tozalangan APK

R8 siz (Xom holat)

APK hajmi 2 barobar og'ir bo'ladi.

Kodni JADX orqali osongina o'qish mumkin.

Barcha keraksiz kutubxona kodlari paket ichida yotadi.

R8 bilan (Professional)

Hajm 40–50% ga qisqaradi.

Klasslar a, b, c qilib chalkashtirilgan, xavfsizlik yuqori.

Faqat foydalanilgan kodlar qoladi, ilova chaqqon ishlaydi.
