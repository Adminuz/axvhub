10-sinfAdvanced Android4-hafta

Savol 1/10

Git'da branch nima?

Branch asosiy loyihaga zarar bermasdan mustaqil ishlash imkonini beruvchi shoxcha.

Savol 2/10

Branch ichki tuzilishi bo'yicha nima?

Branch commitga ishora qiladi, shuning uchun u tez ishlaydi va joy egallamaydi.

Savol 3/10

git checkout -b login-feature nima qiladi?

-b bayrog'i yangi branch yaratadi va avtomatik unga o'tkazadi.

Savol 4/10

Qaysi nom branch nomlash standartiga mos?

Standart nomlar maqsadni bildiradi: feature, bugfix, hotfix, refactor.

Savol 5/10

Merge nima?

Merge ikki branchdagi commitlarni solishtirib, yagona kodga birlashtiradi.

Savol 6/10

Konflikt qachon yuzaga keladi?

Git qaysi versiya to'g'ri ekanini bilmaydi va qo'lda hal qilishni so'raydi.

Savol 7/10

Konflikt belgilarida <<<<<<< HEAD dan keyingi qism qaysi branchniki?

HEAD va ======= orasi joriy branch kodi, pastdagi qism qo'shilayotgan branchniki.

Savol 8/10

Rebase merge'dan nimasi bilan farq qiladi?

Merge ikki tarixni parallel saqlaydi, rebase esa chiziqli tarix hosil qiladi.

Savol 9/10

PR'ni ochgan dasturchi nimani kutadi?

PR: "o'zgarish kiritdim, iltimos tekshirib chiqing" degan rasmiy murojaat.

Savol 10/10

Hamkasbingiz konflikt belgilarini o'chirmay commit qildi. Nima qilasiz?

Belgilar kodda qolsa, loyiha kompilyatsiya bo'lmaydi; ular tuzatilib qayta commit qilinadi.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: branch va pointer, merge, konflikt belgilari, rebase, Pull Request va Code Review (11-dars).
