03

GitHub Actions

YAML konfiguratsiya fayli: build, test, deploy

Workflow: qachon ishga tushadi


name: Android CI
on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

Fayl .github/workflows papkasida turadi. on: push va PR hodisalari.

Workflow: nima bajariladi


jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up JDK
        uses: actions/setup-java@v3
        with:
          distribution: 'temurin'
          java-version: '17'
      - name: Build with Gradle
        run: ./gradlew build

YAML bosqichlari

1. Checkout

Loyiha fayllari yuklanadi.

2. JDK

Java 17 (temurin) o'rnatiladi.

3. Build

./gradlew build ilovani yig'adi.

4. Natija

Muvaffaqiyat yoki xato ko'rsatiladi.

CD: release workflow


name: Release Build
on:
  push:
    tags: [ 'v*' ]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Build Release
        run: ./gradlew bundleRelease
      - name: Upload to Play Store
        uses: r0adkll/upload-google-play@v1

Qisqartirilgan nusxa. Pastga: Secrets

Secrets: maxfiy ma'lumotlar

  • API kalitlari, tokenlar, maxfiy fayllar kodda turmaydi
  • GitHub Actions va GitLab CI'da "Secrets" bo'limi bor
  • Ular shifrlangan holda saqlanadi
  • Tasodifan repozitoriyaga tushib qolishining oldi olinadi

Fayldagi secrets.PLAY_STORE_KEY shu bo'limdan olinadi.
