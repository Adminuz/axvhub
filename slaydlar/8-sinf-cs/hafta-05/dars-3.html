Birinchi commit


mkdir kundalik
cd kundalik
git init
echo "# Mening kundaligim" > README.md
git status            # Untracked files: README.md
git add README.md
git commit -m "README qo'shildi"
git log --oneline     # a1b2c3d README qo'shildi

git status ni o'qish

XabarNima qilamiz
Untracked filesgit add
Changes not staged for commitgit add
Changes to be committedgit commit -m
working tree cleanhammasi saqlangan

Pastga bosing: git log

git log --oneline


c3d4e5f README ga muallif qo'shildi

a1b2c3d README qo'shildi
