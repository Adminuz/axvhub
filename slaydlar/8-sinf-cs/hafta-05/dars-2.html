04

GitHub'da amaliyot

Akkaunt va birinchi repository

Akkaunt yaratish

  1. github.com → Sign up
  2. Email, kuchli parol, username → github.com/username
  3. Emailga kelgan kod bilan tasdiqlash

Pastga bosing: muhim qoida

Muhim

GitHub shartlariga ko'ra — kamida 13 yosh. Akkauntni ota-ona ruxsati bilan oching. README'ga telefon va manzil yozmang.

Birinchi repository

1. New repository

O'ng yuqorida + → New repository.

2. Nom

mening-birinchi-repom — bo'sh joysiz.

3. Public / Private

Hamma ko'radimi yoki faqat siz?

4. README

Add a README file → Create repository.

5. Commit

Edit → yozish → Commit changes → xabar.
