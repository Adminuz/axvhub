Flowgorithm muhiti va interfeys

Nima uchun Flowgorithm?

Mantiqqa e'tibor

Murakkab dasturlash sintaksisiga chalg'imasdan, sof algoritmik mantiqni o'rganishga yordam beradi.

Interaktiv sinov

Chizgan blok-sxemangizni bir zumda ishga tushirib, natijasini konsolda jonli ko'rishingiz mumkin.

Flowgorithm bepul, o'zbek tilini qo'llab-quvvatlaydi va juda kam joy egallaydi!

Dastur interfeysi: Asosiy oynalar

Main oynasi

Code Viewer

Sxemani avtomatik Python, C++ yoki Java kodiga aylantirib beruvchi oyna.

03

Birinchi dastur va xatolarni tuzatish

Blok qo'shish, sintaksis qoidalari va konsol natijasi

Blok qo'shish algoritmi

  1. Main va End orasidagi strelka chizig'ini bosing
  2. Ochilgan menyudan blok turini (masalan, Output) tanlang
  3. O'rnatilgan blok ustiga 2 marta bosib, ifodani yozing
  4. OK tugmasini bosing va F5 bilan ishga tushiring!

Birinchi dastur: Salom, dunyo!

F5 tugmasini bosishingiz bilan konsolda «Salom, dunyo!» yozuvi chiqadi!

Eng ko'p uchraydigan xato: Qo'shtirnoq

Xato usul

Output: Salom, dunyo!

  • Qo'shtirnoq qo'yilmagan!
  • Flowgorithm «Salom»ni e'lon qilinmagan o'zgaruvchi deb o'ylaydi.

To'g'ri usul

Output: "Salom, dunyo!"

  • Matn qo'shtirnoq ichida.
  • Dastur uni to'g'ridan-to'g'ri ekranga chiqaradi.
