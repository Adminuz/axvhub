04

HTTP va HTTPS

Ochiq otkritka yoki yopiq konvert?

HTTP

http://misol.uz

Kirish

Ma'lumot shifrlanmaydi: yo'lda o'qib olinishi mumkin.

HTTPS

https://misol.uz (qulf)

Kirish

Ma'lumot shifrlanadi: yo'lda o'qib bo'lmaydi.

Oldin va keyin

HTTP

Shifrsiz uzatish. Parol yoki karta kiritish xavfli.

HTTPS

Shifrlangan ulanish. Brauzerda qulf belgisi ko'rinadi.

Qulf - ulanish shifrlangan degani, sayt ishonchli degani emas. Domenni ham tekshiring.

Mini-test

Brauzer domen nomini yozilgach birinchi navbatda nima qiladi?

To'g'ri: serverga ulanish uchun IP-manzil kerak, uni DNS beradi.
