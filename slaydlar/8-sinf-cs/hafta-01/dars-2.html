03

Windows muhitida ishlash

Ish stoli, oynalar va tizim sozlamalari

Windows interfeysi elementlari

Start (Boshlash) menyusi

Barcha o'rnatilgan dasturlar, qidiruv paneli va kompyuterni o'chirish/qayta yuklash tugmalari markazi.

Vazifalar paneli (Taskbar)

Ekranning quyi qismidagi mahkamlangan ilovalar, ochiq oynalar va bildirishnomalar (System Tray) maydoni.

Windows oynasi anatomiyasi

Oynalarni ekranga bo'lish (Snap)

1. Birinchi oynani tanlang

Masalan, o'zingiz dars o'rganayotgan brauzer oynasini bosing.

2. Win + Chapga strelka

Oyna ekranning chap 50 foizini to'liq egallaydi.

3. Ikkinchi oynani tanlang

O'ng tomonda chiqadigan ro'yxatdan kod muharririni (VS Code yoki Bloknot) bosing.

4. Professional ish muhiti tayyor!

Ikkala dastur ham ko'z oldingizda yonma-yon ishlaydi, vaqtingiz tejaladi.

Sozlamalar va Boshqaruv paneli

Windows Sozlamalari (Zamonaviy)

Ekran, Wi-Fi tarmog'i, Bluetooth, shaxsiylashtirish, ovoz va o'rnatilgan dasturlar ro'yxatini boshqaruvchi qulay va sodda markaz.

Boshqaruv paneli (Klassik)

Chuqur texnik sozlamalar, ma'muriy boshqaruv, drayverlar va tarmoq adapterlarini batafsil sozlash uchun klassik Windows paneli.

Dasturlarning hayot sikli

Katta xato: Yorliqni o'chirish

«Ish stolidagi o'yin belgisini Delete qilib o'chirdim, lekin diskda joy ochilmadi!»
Yorliq (Shortcut) — shunchaki manzil belgisi. Dasturni to'liq o'chirish uchun Settings -> Installed apps -> Uninstall amali bajarilishi shart!

Foydali Windows tezkor tugmalari

Win + I

Windows Sozlamalarini (Settings) bir zumda ochish

Win + D

Barcha oynalarni yashirib, ish stolini ko'rsatish

Win + E

Fayl boshqaruvchisini (File Explorer) ochish

Alt + Tab

Ochiq dasturlar o'rtasida sichqonchasiz sakrash

Windows interfeysini sozlang

  1. Win + I orqali Sozlamalar darchasini oching va versiyangizni aniqlang.
  2. Brauzer va Bloknot dasturlarini ochib, Win + strelkalar bilan yonma-yon qo'ying.
  3. Alt + Tab orqali ular orasida 3 marta tezkor almashib ko'ring.
  4. Win + D bosib barcha oynalarni ish stoliga yashiring.
