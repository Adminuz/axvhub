01

Kalkulyator loyihasining IPO modeli

Dasturga nima kiradi va qanday natija chiqadi?

Kalkulyatorning 3 bosqichi

INPUT (Kiritish)

1-son (a), Amal turi (+, -, *, /) va 2-son (b).

PROCESS (Jarayon)

Decision orqali amalni aniqlab, hisoblash.

OUTPUT (Natija)

Ekranga to'liq ifoda va javobni chiqarish.

O'zgaruvchilarni to'g'ri tanlash

Sonlar (a, b, natija)

Real turi

  • Foydalanuvchi kasr son kiritishi mumkin (masalan: 2.5).
  • Bo'lish amali kasr natija berishi mumkin.
VS

Amal belgisi (amal)

String turi

  • Matnli belgi: "+", "-", "*", "/".
  • Qo'shtirnoq bilan taqqoslanadi.
02

Decision bloklari zanjiri

To'rt xil amal orasidan to'g'risini qanday tanlaymiz?

Amalni aniqlash zanjiri

  1. amal == "+" bo'lsa $\rightarrow$ natija = a + b
  2. Aks holda amal == "-" bo'lsa $\rightarrow$ natija = a - b
  3. Aks holda amal == "*" bo'lsa $\rightarrow$ natija = a * b
  4. Aks holda amal == "/" bo'lsa $\rightarrow$ natija = a / b
  5. Aks holda $\rightarrow$ «Noto'g'ri amal!» xabari.

Muhim qoida: Qo'shtirnoq

Amal belgisi String bo'lgani uchun Decision ichida albatta qo'shtirnoq bo'lishi shart: amal == "+"!
