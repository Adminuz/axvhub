Loyihani to'liq testlash va professional ko'rinishga keltirish.

01

Nolga bo'lish (Division by Zero) nima?

Dasturni qotirib qo'yadigan xatolikdan himoyalanamiz

Nima uchun nolga bo'lib bo'lmaydi?

Himoyasiz dastur

b = 0 bo'lganda natija = a / b bajarilsa:

  • Kompyuter qotib qoladi yoki favqulodda to'xtaydi (Crash).
  • Foydalanuvchi hech narsani tushunmay qoladi.
VS

Himoyalangan dastur

Bo'lishdan oldin b == 0 tekshiriladi:

  • Agar nol bo'lsa: «0 ga bo'lish mumkin emas!» deb ogohlantiradi.
  • Dastur to'xtab qolmay, xavfsiz davom etadi.

Himoya Decision blokining tuzilishi

True: b == 0

Output "Xatolik: Nolga bo'lish mumkin emas!"

Hech qanday bo'lish amali bajarilmaydi.

False: b != 0

natija = a / b

Xavfsiz hisoblanib, natija ekranga ko'rsatiladi.

02

While sikli orqali uzluksiz menyu

Dastur bir marta ishlab tugab qolmasin!

Qayta ishlash mexanizmi

  1. Boshida davom = "ha" o'rnatiladi.
  2. While davom == "ha" sikli ochiladi.
  3. Sikl ichida barcha kiritish va hisoblashlar bajariladi.
  4. Oxirida so'raladi: "Yana hisoblaysizmi? (ha/yo'q)".
  5. Agar "yo'q" deyilsa, sikl to'xtaydi va minnatdorchilik bildiriladi.
