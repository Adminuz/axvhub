Juft bo'lib ishlash

  1. Sinfdoshingizning Public repository'sini git clone qiling.
  2. O'z repo'ingizda yangi-sahifa branch'ini yarating, fayl qo'shing va main ga merge qiling.
  3. README.md ni Markdown bilan to'ldiring, commit va push qiling.
