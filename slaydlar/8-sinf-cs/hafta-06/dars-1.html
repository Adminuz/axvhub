remote va push

Loyiha internetga chiqadi

Push yo'li

Kundalik loyihasini GitHub'ga yuklash


cd kundalik
git remote add origin https://github.com/username/kundalik.git
git remote -v
git branch -M main
git push -u origin main
Keyingi o'zgarishlarda: git add . → git commit -m "xabar" → git push. Commit qilmagan o'zgarish push bilan yuklanmaydi.

«Kundalik» GitHub'da

  1. GitHub'da kundalik nomli bo'sh repository yarating.
  2. Kompyuterda git remote add origin ... va git push -u origin main ni bajaring.
  3. Yana bitta o'zgarish qiling: add, commit, push, GitHub'da yangi commitni toping.
