Web va Mobile: qisqacha

Web Back-end  : Python, JavaScript (Node.js), baza
Android       : Kotlin
iPhone (iOS)  : Swift
Ikkala tizim  : Flutter, React Native
Hozir hamma narsani o'rganish shart emas. Birinchi qadam — HTML va oddiy sahifa yaratish: shu yo'l kelasi bosqichlarda Web Full-Stack yo'nalishiga olib boradi.
