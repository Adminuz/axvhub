UI dizayn

Ta'rif

UI-dizayn — tugmalar, menyular, belgilar va o'yinchi o'zaro ta'sir qiladigan boshqa elementlarni o'z ichiga olgan o'yinning vizual va interaktiv qismini yaratish jarayoni.

Ma'lumot

Sog'lik, energiya, inventar.

Boshqaruv

Menyu, pauza, qurol tanlash, sozlamalar.

Aloqa

Xarita, kvestlar, dialoglar.

UI va UX

Sifatli UI

O'yinchi tez tushunadi, o'yin muhitiga sho'ng'iydi — taassurot yaxshi.
VS

Yomon UI

Chalg'itadi, adashtiradi, tushkunlikka soladi — o'yinchi ketadi.

UI-dizaynerning 5 vazifasi

1. Axborotni vizual uzatish

Grafika, animatsiya va tovush bilan tushunarli format.

2. Soddalik va aniqlik

Chalg'ituvchi omillar kam, o'zaro ta'sir sodda.

3. Muvofiq uyg'unlik

Interfeys o'yin uslubini to'ldiradi.

4. Funksional imkoniyatlar

Qulay boshqaruv vositalari.

5. Estetika va uslub

Ranglar, shriftlar, animatsiyalar — tanib olinadigan uslub.

Asosiy UI elementlari

02

Tugmalar turlari

Primary, Secondary, interaktiv

Uch tur

Primary

Boshlash, davom ettirish, tasdiqlash: Start, OK.

Secondary

Bekor qilish, ortga qaytish: Cancel, Back.

Interaktiv

Hover, pressed, yoritish yoki animatsiya effektlari bilan.

Ierarxiya

Tugma dizayni talablari

O'lcham va joy

Bosish qulay, Start odatda markazda.

Ajralib turish

Rang va shakl boshqa elementlardan farqli.

Aniq holatlar

Normal, hover, bosilgan — farqli.

«Start Game» odatda markazda va e'tiborni tortuvchi rangda — yashil yoki ko'k.

Mini-test

«Cancel» tugmasi qaysi turga kiradi?

Bekor qilish va ortga qaytish — ikkinchi darajali (Secondary) harakatlar.
03

Tugma holatlari

Normal → Hover → Pressed

Uch holat

Holatni nima bildiradi?

Normal

bosing

Asosiy rang, Drop Shadow. «Meni bosish mumkin».

Hover

bosing

Ochroq rang, Outer Glow. Geympadda — tanlangan (focus).

Pressed

bosing

To'qroq, soyasiz, 2–4 px pastga. «Qabul qilindi».

Qo'shimcha: Disabled — kulrang, bosib bo'lmaydi.

04

Photoshop amaliyoti

Uslubiy ko'rsatma, 1.4-mashg'ulot

START tugmasi: 6 qadam

  1. File → New: 1920×1080 px, 72 ppi, RGB, «O'yin menyusi».
  2. Rectangle Tool (U): to'rtburchak, Color Picker bilan rang.
  3. Move Tool (V): markazga joylash.
  4. Properties → Corners: 30 px — yumaloq burchak.
  5. Properties → Stroke: rang va qalinlik.
  6. Text Tool (T): «START», shrift va o'lcham, markazga.

Layer Styles

Gradient Overlay Drop Shadow Inner Glow Outer Glow Bevel & Emboss Stroke
2–3 effekt yetarli. Hammasi birdaniga — tugma «og'ir» va o'qilmaydigan bo'ladi.
