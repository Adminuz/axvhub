class OrderObserver(Protocol):
    """Barcha kuzatuvchilar uchun yagona shartnoma (kontrakt)."""
    def update(self, order_id: str, amount: float) -> None:
        ...

Subject (Publisher) kodi

class OrderSubject:
    def __init__(self) -> None:
        self._observers: List[OrderObserver] = []

    def attach(self, observer: OrderObserver) -> None:
        if observer not in self._observers:
            self._observers.append(observer)

    def detach(self, observer: OrderObserver) -> None:
        self._observers.remove(observer)

    def notify(self, order_id: str, amount: float) -> None:
        for observer in self._observers:
            try:
                observer.update(order_id, amount)
            except Exception as e:
                # Bitta kuzatuvchi xatosi boshqalarni to'xtatmaydi!
                print(f"Xatolik kuzatuvchida: {e}")
02

Event-Driven arxitektura va EventBus

Monolitdan ko'p qatlamli va mikroxizmatli tizimlarga o'tish ko'prigi

Observer vs Centralized EventBus

Klassik Observer (1:N)

Kuzatuvchilar to'g'ridan-to'g'ri bitta Subject obyektiga yopishadi (attach).

  • Subject o'zi ro'yxatni boshqaradi.
  • Kichik va bitta modul ichida qulay.
  • Modullar ko'paysa o'zaro bog'liqlik oshishi mumkin.

EventBus (N:M)

Barcha hodisalar markaziy magistral (broker) orqali e'lon qilinadi va tarqatiladi.

  • Nomli hodisalar: "user:created", "order:paid".
  • Publishers va Subscribers bir-birini umuman ko'rmaydi.
  • Zamonaviy Backend (Kafka, RabbitMQ, Redis) asosi.

EventBus arxitekturasi

Python'da oddiy EventBus kodi

from collections import defaultdict
from typing import Callable, Dict, List, Any

class EventBus:
    def __init__(self) -> None:
        self._subscribers: Dict[str, List[Callable[[Any], None]]] = defaultdict(list)

    def subscribe(self, event_name: str, handler: Callable[[Any], None]) -> None:
        self._subscribers[event_name].append(handler)

    def publish(self, event_name: str, payload: Any) -> None:
        for handler in self._subscribers.get(event_name, []):
            try:
                handler(payload)
            except Exception as err:
                print(f"[EventBus Xato] {event_name} -> {handler.__name__}: {err}")

# Foydalanish:
bus = EventBus()
bus.subscribe("book:borrowed", lambda data: print(f"Kitob berildi: {data['title']}"))
bus.publish("book:borrowed", {"title": "Clean Architecture", "user": "Ali"})

Hodisalar arxitekturasi xavflari

1. Xotira oqimi (Memory Leak)

Kuzatuvchi obyekt o'chirilganda unsubscribe qilinmasa, u Subject ro'yxatida qolib GC tomonidan tozalanmaydi.

2. Tartibsiz bajarilish

Kuzatuvchilarning chaqirilish ketma-ketligiga suyanmang. Ular bir-biriga bog'liq bo'lmasligi shart.

3. Siklik chaqiruvlar

A hodisasi B ni chaqirib, B hodisasi yana A ni chaqirsa cheksiz rekursiya yuzaga keladi.

Unit Test va Mock bilan sinash

Hodisalarni haqiqiy tashqi xizmatlarsiz 100% mustaqil tekshirish

Observer'ni Mock yordamida testlash

from unittest.mock import MagicMock
from order_publisher import OrderSubject

def test_order_subject_notifies_all_observers():
    # 1. Arrange: Subject va soxta kuzatuvchilar
    subject = OrderSubject()
    mock_email = MagicMock()
    mock_bonus = MagicMock()

    subject.attach(mock_email)
    subject.attach(mock_bonus)

    # 2. Act: Hodisani e'lon qilish
    subject.notify(order_id="ORD-101", amount=50000.0)

    # 3. Assert: Har bir mock chaqirilganini tekshirish
    mock_email.update.assert_called_once_with("ORD-101", 50000.0)
    mock_bonus.update.assert_called_once_with("ORD-101", 50000.0)
