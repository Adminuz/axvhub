Savol 1/10

Git nima?

Git lokal dastur, internet shart emas. GitHub esa uning atrofidagi veb-xizmat.

Savol 2/10

Yangi bo'sh papkada repozitoriy yaratish buyrug'i qaysi?

git init yashirin .git/ katalogini yaratadi, -b main boshlang'ich shox nomini beradi.

Savol 3/10

Git'ning uchta zonasi to'g'ri tartibda qaysi?

git add ishchi papkadan stagingga, git commit stagingdan tarixga o'tkazadi.

Savol 4/10

git status -s da ?? belgisi nimani bildiradi?

?? Git hali kuzatmaydigan yangi fayl. A stagingga qo'shilgan, M o'zgargan lekin stagingda emas.

Savol 5/10

git add a.txt dan keyin a.txt ga yana qator qo'shildi. git status -s nima ko'rsatadi?

Birinchi harf A: fayl stagingda. Ikkinchi harf M: ishchi papkada stagingga tushmagan o'zgarish bor.

Savol 6/10

git add dan keyin git diff bo'sh chiqdi. Sababi nima?

git diff ishchi papka va stagingni solishtiradi. Staging va oxirgi commit farqi --staged bilan ko'rinadi.

Savol 7/10

main da turib feature/greeting ni birlashtirish buyrug'i qaysi?

Merge qabul qiluvchi shoxda (main) turib bajariladi. -d esa birlashgan shoxni o'chiradi.

Savol 8/10

Saqlanmagan o'zgarishni bekor qiladigan, lekin qaytarib bo'lmaydigan buyruq qaysi?

git restore ishchi o'zgarishni o'chiradi va uni tiklab bo'lmaydi. Ehtiyot bo'ling.

Savol 9/10

Konfliktli faylda <<<<<<< HEAD va ======= belgilari orasidagi qism nimani anglatadi?

HEAD ostidagi qism joriy shoxniki; ======= dan keyingisi birlashtirilayotgan shoxniki.

Savol 10/10

Umumiy shoxda xato commitni xavfsiz bekor qilish kerak. Qaysi buyruq mos va nega?

Revert yangi commit qo'shadi, tarix saqlanadi, shuning uchun umumiy shoxlarda xavfsiz.

Natijangiz

10 dan 9+

A'lo. Mavzu yaxshi o'zlashtirilgan.

10 dan 6-8

Yaxshi. Xato qilgan savollar izohini qayta o'qing.

5 va undan kam

Konspekt va slaydlarni takrorlang, so'ng testni qayta yeching.

Takrorlang: Git zonalari, git status -s belgilari, branch va merge, konfliktni hal qilish, restore va revert farqi.
